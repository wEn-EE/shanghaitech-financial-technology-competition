## 22.1 滚动协方差、收缩估计与正定性

### 22.1.1 从收益面板到共同样本矩阵

设同频收益向量为 $r_t\in\mathbb R^p$ 。每一列对应固定资产，每一行对应相同经济时间区间。必须先统一币种视角、价格或总回报口径、交易时段及信息可用性。

协方差的总体定义是：

```math
\Sigma_{ij}=\mathrm E[(r_i-\mu_i)(r_j-\mu_j)].
```

它描述共同变动，量纲为两个收益单位的乘积。若两列都用小数收益，协方差是小数收益平方；把一列误乘100，相关可能不变，协方差和组合风险却改变。

窗口内有 $n$ 条完整共同观测。定义均值和中心化矩阵：

```math
\bar r=\frac1n\sum_{t=1}^n r_t,
\qquad
X_{t,:}=(r_t-\bar r)^\top,
\qquad
S=\frac{X^\top X}{n-1}.
```

逐元素展开便得到样本协方差。这里 $n\geq2$ ，分母为 $n-1$ 。NumPy默认把行作为变量，本章数据是“行时间、列资产”，调用参考实现时必须使用rowvar=False。[NumPy cov文档](https://numpy.org/doc/2.1/reference/generated/numpy.cov.html)

### 22.1.2 半正定为什么是必要条件

**半正定（Positive Semidefinite，PSD）**指任意向量 $w$ 都满足 $w^\top S w\geq0$ 。对共同样本矩阵：

```math
w^\top S w
=\frac{w^\top X^\top Xw}{n-1}
=\frac{(Xw)^\top(Xw)}{n-1}
=\frac{\lVert Xw\rVert_2^2}{n-1}
\geq0.
```

金融含义： $w^\top S w$ 是固定权重线性组合收益的样本方差，不能为负。

**正定（Positive Definite，PD）**要求所有非零 $w$ 的二次型严格大于0。它比半正定更强。

由于中心化后各行之和为零：

```math
\mathrm{rank}(S)=\mathrm{rank}(X)
\leq\min(p,n-1).
```

所以当 $p\geq n$ 时，样本协方差必然奇异。即使 $n\gt p$ ，重复资产、复制特征或精确线性关系也可能造成奇异。

奇异不代表协方差“计算错了”，而是不能稳定求逆。最小方差组合、马氏距离和高斯似然若直接使用逆矩阵，就会遇到问题。

### 22.1.3 从协方差到相关矩阵

假设各资产方差严格为正。令：

```math
D=\mathrm{diag}(\sqrt{S_{11}},\ldots,\sqrt{S_{pp}}),
\qquad
R=D^{-1}SD^{-1}.
```

于是：

```math
R_{ij}=\frac{S_{ij}}{\sqrt{S_{ii}S_{jj}}},
\qquad R_{ii}=1.
```

对任意 $v$ ， $v^\top Rv=(D^{-1}v)^\top S(D^{-1}v)\geq0$ ，所以该归一化保留半正定性。

常量资产的方差为0，此时相关未定义。不能把0/0强行设为0并继续宣称得到有效估计。应报告常量、停牌或陈旧报价，并考虑移出当前关联估计的有效资产集合。

资产集合改变时，平均相关和最大特征值也会改变；因此每个结果必须携带资产列表，而不能只存矩阵数字。

### 22.1.4 逐对删除的陷阱

**逐对删除（Pairwise Deletion）**指每一对资产分别取两者都非缺失的观测。它利用更多局部数据，但不同元素来自不同样本，未必存在一个共同的中心化矩阵 $X$ 。

考虑六行三资产数据：

| 行 | A | B | C |
|---:|---:|---:|---:|
| 1 | 1 | 1 | 缺失 |
| 2 | −1 | −1 | 缺失 |
| 3 | 1 | 缺失 | 1 |
| 4 | −1 | 缺失 | −1 |
| 5 | 缺失 | 1 | −1 |
| 6 | 缺失 | −1 | 1 |

逐对相关为AB=1、AC=1、BC=−1：

```math
R_{\mathrm{pair}}=
\begin{pmatrix}
1&1&1\\[0pt]
1&1&-1\\[0pt]
1&-1&1
\end{pmatrix}.
```

令 $v=(-1,1,1)^\top$ ，直接相乘得到 $R_{\mathrm{pair}}v=-v$ ，所以：

```math
v^\top R_{\mathrm{pair}}v=-v^\top v=-3.
```

另外两个特征值为2，因此全部特征值是−1、2、2。每个元素都在合法区间内，对角线也全为1，但整体不是合法相关矩阵。pandas文档也明确提示缺失条件下的协方差结果不保证半正定。[DataFrame.cov文档](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.cov.html)

这不是浮点误差，而是样本集合不一致造成的结构问题。把明显负特征值称为“数值噪声”会掩盖问题。

### 22.1.5 线性收缩的结构与保证

**收缩估计（Shrinkage Estimation）**把样本估计与较简单的目标矩阵组合：

```math
\widehat\Sigma_\alpha=(1-\alpha)S+\alpha T,
\qquad 0\leq\alpha\leq1.
```

本章选择球形目标：

```math
T=\mu I,\qquad \mu=\frac{\mathrm{tr}(S)}p>0.
```

若 $S=U\Lambda U^\top$ ，由于单位矩阵与任何矩阵共享特征向量：

```math
\widehat\Sigma_\alpha
=U\left((1-\alpha)\Lambda+\alpha\mu I\right)U^\top.
```

每个特征值因此变为：

```math
\widehat\lambda_i=(1-\alpha)\lambda_i+\alpha\mu.
```

当原始 $S$ 半正定且 $\alpha\gt 0$ 时：

```math
\widehat\lambda_{\min}\geq\alpha\mu>0.
```

这给出正定保证。迹不变，因为：

```math
\mathrm{tr}(\widehat\Sigma_\alpha)
=(1-\alpha)\mathrm{tr}(S)+\alpha p\mu
=\mathrm{tr}(S).
```

球形目标把各资产方差向同一均值拉近，可能不适合波动尺度差异极大的资产。另一种目标是diag(S)，它保留样本方差、压缩非对角项；但若某个方差为0，就不能据此得到严格正定保证。

收缩降低不稳定性，也引入偏差。它不能创造缺失的信息，且不能把任意不定矩阵都自动修复为正定：上述下界依赖原始 $S$ 半正定。

### 22.1.6 为什么收缩可能降低均方误差

先考虑固定目标 $T$ 、无偏估计 $S$ ，令 $A=S-\Sigma$ 、 $B=T-\Sigma$ ，则：

```math
\widehat\Sigma_\alpha-\Sigma=(1-\alpha)A+\alpha B.
```

平方Frobenius范数并取期望：

```math
\mathrm E\lVert\widehat\Sigma_\alpha-\Sigma\rVert_F^2
=(1-\alpha)^2V+\alpha^2B_0,
```

其中 $V=\mathrm E\lVert A\rVert_F^2$ 、 $B_0=\lVert B\rVert_F^2$ 。交叉项为0，因为 $B$ 固定且 $\mathrm E[A]=0$ 。

对 $\alpha$ 求导：

```math
-2(1-\alpha)V+2\alpha B_0=0,
\qquad
\alpha^*=\frac{V}{V+B_0}.
```

这说明样本噪声大时可以更依赖目标，目标偏差大时应减小收缩。但真实 $\Sigma$ 未知，且本章目标中的 $\mu$ 也由样本估计，因此这个推导只是解释偏差—方差权衡，不是直接可用的Ledoit–Wolf公式。

Ledoit与Wolf研究了数据驱动收缩估计；其方法有具体渐近条件和估计步骤，不能把任意固定alpha都叫作Ledoit–Wolf。[作者论文](https://www.ledoit.net/Well-conditioned2004.pdf)

本章预设alpha=0.2，不通过测试期调参，也不声称这是最优值。

### 22.1.7 数值修复不是统计修复

若仅有舍入级别的轻微不对称，可先取 $(A+A^\top)/2$ 。对实对称矩阵分解后，把负特征值裁到0，可得到半正定矩阵，但对角线通常不再为1。

重新按对角线归一化可以得到另一相关矩阵，前提是对角线正；它通常不是原矩阵在指定范数下的最近相关矩阵。Higham研究的最近相关矩阵问题同时约束半正定和单位对角线。[原论文大学存档](https://eprints.maths.manchester.ac.uk/232/01/paper3.pdf)

工程应保留修复前矩阵、负特征值大小、修复距离和触发原因。若问题来自时段错配或逐对样本，首先修正估计过程。数学投影不能证明经济关系已可信。

## 22.2 动态条件相关、尾部共振与网络特征

### 22.2.1 滚动估计与预测时序

滚动窗口 $[t-k+1,t]$ 的协方差在观察到第t期收益后才能计算，属于截至t的状态描述。

预测第t期风险的矩阵则必须只依赖截至t−1的信息，记为 $H_{t\mid t-1}$ 。两者不可用同一个时间字段含混表示。

窗口较短能迅速反应变化，但样本噪声大；窗口较长稳定，却把新旧制度混合。改变窗口不是免费提升：必须在同一时间划分下评价响应速度、估计波动和误报。

### 22.2.2 EWMA协方差递推

**指数加权移动平均（Exponentially Weighted Moving Average，EWMA）**可用于中心化收益外积：

```math
H_{t+1\mid t}
=\lambda H_{t\mid t-1}
+(1-\lambda)u_tu_t^\top,\qquad 0<\lambda<1.
```

$u_t=r_t-\widehat\mu$ ，本章 $\widehat\mu$ 在训练期冻结。若假设均值为0也应明确说明。

外积半正定，因为：

```math
w^\top u_tu_t^\top w=(w^\top u_t)^2\geq0.
```

所以正权重组合保留半正定；若初始H正定且lambda大于0，有限步更新保持正定。

递推展开为：

```math
H_{t+1}
=\lambda^{t-t_0+1}H_{t_0}
+(1-\lambda)\sum_{s=t_0}^{t}\lambda^{t-s}u_su_s^\top.
```

它是围绕固定均值的加权二阶矩，不等同于每期重新估计均值的无偏滚动样本协方差。EWMA没有长期均值回归常数项，不应把它直接描述成完整DCC。

### 22.2.3 DCC的分层机制

**动态条件相关（Dynamic Conditional Correlation，DCC）**将条件协方差分解为：

```math
H_t=D_tR_tD_t,
\qquad
D_t=\mathrm{diag}(\sqrt{h_{1t}},\ldots,\sqrt{h_{pt}}).
```

第一层分别建模条件方差，例如：

```math
h_{it}=\omega_i+\alpha_i\epsilon_{i,t-1}^2+\beta_i h_{i,t-1}.
```

第二层使用标准化残差 $z_t=D_t^{-1}\epsilon_t$ 更新相关驱动矩阵：

```math
Q_t=(1-a-b)\bar Q
+a z_{t-1}z_{t-1}^\top+bQ_{t-1}.
```

第三层归一化：

```math
R_t=
\mathrm{diag}(Q_t)^{-1/2}
Q_t
\mathrm{diag}(Q_t)^{-1/2}.
```

这里diag(Q)表示由Q的对角元素组成的对角矩阵。Q通常不是相关矩阵，因为它的对角线不必等于1。

若 $a,b\geq0$ 、 $a+b\lt 1$ ，且 $\bar Q$ 正定、初始Q半正定，则Q是包含正定项的非负组合，因而正定。这个代数条件保障递推结构，不足以单独证明任意数据上的估计一致性或全部平稳性性质。

标准DCC强调先剥离各资产时变波动，再估计关联；否则协方差变大可能仅仅来自波动上升。[Engle（2002）原论文](https://faculty.washington.edu/ezivot/econ589/EngleDCCJBES.pdf)

### 22.2.4 DCC估计目标与边界

在条件高斯假设下，忽略常数，一期负对数似然为：

```math
\frac12\left(\log|H_t|+\epsilon_t^\top H_t^{-1}\epsilon_t\right).
```

由分解得到：

```math
|H_t|=|D_t|^2|R_t|,
\qquad
H_t^{-1}=D_t^{-1}R_t^{-1}D_t^{-1}.
```

代入：

```math
\frac12\left(
2\sum_i\log\sqrt{h_{it}}
+\log|R_t|+z_t^\top R_t^{-1}z_t
\right).
```

固定第一阶段条件波动后，可以优化与相关参数有关的部分。厚尾下常把它当作准似然，但参数不确定性和模型失配仍须考虑；本书后续GARCH章节再实现完整拟合。

本章代码只给出DCC递推原语及正定测试，没有拟合单资产GARCH，也没有把固定标准差残差冒充完整DCC估计结果。训练期的均值、方差参数、长期目标和超参数都必须冻结后进入未来评价。

### 22.2.5 尾部共振与小样本分母

相关是整体二阶关系，可能掩盖联合下跌。对训练期冻结的下尾阈值 $q_i,q_j$ ，窗口内可估计：

```math
\widehat p_{i\mid j}
=\frac{\sum_t\mathbf1(r_{it}\leq q_i,\ r_{jt}\leq q_j)}
{\sum_t\mathbf1(r_{jt}\leq q_j)}.
```

分子分母必须使用同一对资产共同可见的样本。分母为0时输出未知；只出现2个触发、其中1个共跌，虽得到50%，证据仍很弱，应同时展示1/2。

**下尾依赖系数（Lower-Tail Dependence Coefficient）**是极限对象：

```math
\lambda_L=\lim_{u\downarrow0}
P(F_i(r_i)\leq u\mid F_j(r_j)\leq u).
```

有限样本的5%条件共跌比例不是该极限的无偏估计。一个固定阈值特征可用于监控，但不能直接宣传为已准确估计极端尾依赖。

用当前全样本分位数回算早期阈值会泄漏；用各滚动窗口自己的分位数则改变比较基准。两种口径需要明确区分。

### 22.2.6 网络特征的含义

将资产作为节点，可以按 $|\rho_{ij}|\gt \tau$ 连边。阈值、正负边处理和资产集合都应冻结或记录版本。

平均绝对相关：

```math
\bar\rho_{\mathrm{abs}}
=\frac{2}{p(p-1)}\sum_{i<j}|\rho_{ij}|.
```

它度量线性关联强度，但会把强负相关也计为“强关联”。因此还应单独显示平均有符号相关、股债相关和负边占比。

相关矩阵迹为p，故最大特征值占比为：

```math
C_1=\frac{\lambda_{\max}(R)}p.
```

若R是单位矩阵， $C_1=1/p$ ；所有资产完全同向时， $C_1=1$ 。它描述共同变动集中程度，不说明共同因子的经济身份。

常用相关距离：

```math
d_{ij}=\sqrt{2(1-\rho_{ij})}.
```

对在共同样本上中心化并归一为单位长度的向量 $v_i,v_j$ ：

```math
\lVert v_i-v_j\rVert^2
=1+1-2v_i^\top v_j
=2(1-\rho_{ij}).
```

所以该距离有欧氏解释。若相关来自不一致的逐对样本，未必存在这些共同空间向量；若使用绝对相关定义距离，经济解释也变了。

相关网络是无向统计依赖图。共同政策冲击、相同计价货币或交易时间差都可能产生连边。识别因果传染需要额外机制、识别假设和证据，不能把中心度最高的节点直接叫作危机源头。

## 22.3 缺失资产、异步交易和估计稳定性

### 22.3.1 缺失处理的三种路线

| 路线 | 优点 | 局限 |
|---|---|---|
| 完整共同样本 | 保持统一Gram矩阵结构 | 丢失部分可用信息，样本少；缺失非随机时有选择偏差 |
| 逐对估计 | 每一对利用更多数据 | 可能不半正定；每对样本量和时期不同 |
| 显式概率模型 | 可通过条件分布处理部分缺失 | 增加分布与机制假设，拟合及审计复杂 |

本章选择固定40期日历窗口内的完整共同观测，不是向过去无限扩展直到凑满40条。缺失行保留在原始输入，估计结果返回实际参与的行号与数量。

对EWMA，本章缺少任一资产时跳过整次外积更新，保留原矩阵并记录last_update。这样可保持正定，但更新间隔不再固定；绝不能把这个矩阵假装为刚刚观察了全部行情后的新估计。

另一种做法是只估计当前可用资产子矩阵，但必须改变资产集合标签。用0填缺失收益会混淆“没有观测”和“没有价格变化”。

### 22.3.2 异步与陈旧价格

若A在某分钟更新、B未更新，将B价格前填再计算收益，可能得到许多零收益和迟到的大跳变，导致同步相关下降、滞后相关升高。

应先执行第19章的时间对齐并记录报价年龄。不能在整段历史中使用“最近时间”连接，因为最近记录可能来自未来。对于异步高频估计可研究刷新时间采样或专门估计量，但它们各自依赖观测机制与微观结构假设。

交易休市、供应商中断和真实零成交需要不同质量状态。相关变化若与陈旧比例同步上升，首先应排查数据原因。

### 22.3.3 稳定性、有效样本与评估

相邻40期滚动窗口通常共享39期数据。因此连续100个相关点不是100个独立证据，不能据此直接计算普通独立样本标准误。

常见报告字段应包括：窗口、完整样本数、覆盖率、参与资产、最小特征值、条件数、更新年龄、估计器与参数版本。

对正定矩阵，谱条件数为：

```math
\kappa_2(S)=\frac{\lambda_{\max}(S)}{\lambda_{\min}(S)}.
```

很小的最小特征值意味着求逆对扰动敏感。风险监控不一定需要求逆；如果只是展示相关热图，不应为了形式完整而引入不必要的逆矩阵。

评估分三层：

1. 数学约束：对称、有限、对角、特征值和方差非负。
2. 因果一致性：未来扰动不改变过去，预测矩阵先于本期收益。
3. 统计用途：在冻结的未来区间比较风险评分、覆盖或似然，且注明真实协方差不可直接观察。

下一期外积是条件协方差的噪声代理；若使用它比较估计误差，仍需要均值与可积性等条件。单个外积不能当作无误差“标准答案”。

## 22.4 完整实验：四资产滚动关联与风险矩阵

### 22.4.1 数据与时间协议

4项资产分别为EQ_DEMO、BOND_DEMO、GOLD_DEMO、FX_DEMO。240期人工小数收益由共同因子生成：

```math
r_{it}=0.01\left(b_i f_t+\sqrt{1-b_i^2}e_{it}\right).
```

$f_t,e_{it}$ 相互独立标准正态，故：

```math
\mathrm{Var}(r_{it})=10^{-4},
\qquad
\mathrm{Corr}(r_{it},r_{jt})=b_ib_j\quad(i\neq j).
```

推导：共同因子的协方差为 $10^{-4}b_ib_j$ ，独立残差交叉项为0；每项方差为 $10^{-4}[b_i^2+(1-b_i^2)]$ 。

前140期载荷为(0.8,−0.5,0.2,−0.2)，后100期为(0.85,0.8,0.65,0.6)。理论股债相关因此从−0.4变为0.68，而各资产方差不变。这把相关变化与边际波动变化分开。

第165期黄金收益设为缺失。训练用前60期，窗口40，固定alpha=0.2，EWMA衰减0.94。输入t在t+1可用，特征计算零延迟；这些均为人工协议。

forecast_cov在读取本期收益前保存，updated_cov在读取后更新。前60期训练产物假设在时刻60就绪；本实验不输出训练期内的伪在线预测。

```python
"""SYNTHETIC four-asset covariance lab; requires existing NumPy."""
from pathlib import Path
from datetime import datetime, timezone
import hashlib
import json
import numpy as np

ASSETS = ["EQ_DEMO", "BOND_DEMO", "GOLD_DEMO", "FX_DEMO"]


def covariance(x):
    x = np.asarray(x, dtype=float)
    if x.ndim != 2 or len(x) < 2 or not np.isfinite(x).all():
        raise ValueError("need at least two complete observations")
    y = x - x.mean(axis=0)
    return y.T @ y / (len(x) - 1)


def correlation(s):
    d = np.diag(s)
    if not np.isfinite(s).all() or np.any(d <= 0):
        raise ValueError("positive finite variances required")
    return s / np.sqrt(np.outer(d, d))


def shrink(s, alpha=0.2):
    if not 0 <= alpha <= 1:
        raise ValueError("alpha outside [0,1]")
    mu = np.trace(s) / len(s)
    if mu <= 0:
        raise ValueError("nonpositive average variance")
    return (1 - alpha) * s + alpha * mu * np.eye(len(s))


def dcc_step(q, z, target, a=0.03, b=0.94):
    if a < 0 or b < 0 or a + b >= 1:
        raise ValueError("invalid DCC parameters")
    new = (1 - a - b) * target + a * np.outer(z, z) + b * q
    return new, correlation(new)


def pairwise_example():
    x = np.array([[1, 1, np.nan], [-1, -1, np.nan],
                  [1, np.nan, 1], [-1, np.nan, -1],
                  [np.nan, 1, -1], [np.nan, -1, 1]])
    r = np.eye(3)
    for i in range(3):
        for j in range(i):
            keep = np.isfinite(x[:, i]) & np.isfinite(x[:, j])
            r[i, j] = r[j, i] = np.corrcoef(x[keep, i], x[keep, j])[0, 1]
    return x, r


def samples(n=240):
    rng = np.random.default_rng(20261112)
    rows = []
    for t in range(n):
        f = rng.normal()
        e = rng.normal(size=4)
        load = np.array([0.8, -0.5, 0.2, -0.2] if t < 140
                        else [0.85, 0.8, 0.65, 0.6])
        r = 0.01 * (load * f + np.sqrt(1 - load**2) * e)
        if t == 165:
            r[2] = np.nan
        rows.append(r)
    return np.array(rows)


def replay(x, train=60, window=40, decay=0.94):
    if len(x) < train or not 0 < decay < 1:
        raise ValueError("invalid history or decay")
    mean = x[:train].mean(axis=0)
    h = shrink(covariance(x[:train]))
    records = []
    last_update = train - 1
    for t in range(train, len(x)):
        forecast = h.copy()  # Available before observing return t.
        block = x[max(0, t-window+1):t+1]
        keep = np.isfinite(block).all(axis=1)
        ids = np.arange(max(0, t-window+1), t+1)[keep]
        s = covariance(block[keep]) if keep.sum() >= 10 else None
        if s is not None and np.all(np.diag(s) > 0):
            shrunk = shrink(s)
            r = correlation(shrunk)
            eig = np.linalg.eigvalsh(r)
            metrics = {"eq_bond": float(r[0, 1]),
                       "mean_abs_corr": float(np.abs(r[np.triu_indices(4, 1)]).mean()),
                       "largest_share": float(eig[-1] / 4),
                       "min_eigenvalue": float(np.linalg.eigvalsh(shrunk)[0])}
        else:
            metrics = None
        observed = bool(np.isfinite(x[t]).all())
        if observed:
            u = x[t] - mean
            h = decay * h + (1 - decay) * np.outer(u, u)
            last_update = t
        records.append({"t": t, "ready": t + 1,
                        "forecast_cov": forecast.tolist(),
                        "updated_cov": h.tolist(), "updated": observed,
                        "last_update": last_update, "complete_ids": ids.tolist(),
                        "n_complete": int(keep.sum()), "metrics": metrics})
    return {"mean": mean.tolist(), "records": records}


def run():
    x = samples()
    result = replay(x)
    raw, bad = pairwise_example()
    result.update({
        "data_kind": "SYNTHETIC", "seed": 20261112, "assets": ASSETS,
        "config": {"train": 60, "window": 40, "decay": 0.94, "alpha": 0.2},
        "input": [[None if not np.isfinite(v) else float(v) for v in row] for row in x],
        "invalid_pairwise_corr": bad.tolist(),
        "invalid_eigenvalues": np.linalg.eigvalsh(bad).tolist()
    })
    return result


def main():
    result = run()
    out = Path(__file__).parent / "runs" / datetime.now(timezone.utc).strftime("run_%Y%m%dT%H%M%S_%fZ")
    out.mkdir(parents=True)
    p = out / "results.json"
    p.write_text(json.dumps(result, indent=2, allow_nan=False), encoding="utf-8")
    manifest = {"numpy": np.__version__,
                "code_sha256": hashlib.sha256(Path(__file__).read_bytes()).hexdigest(),
                "result_sha256": hashlib.sha256(p.read_bytes()).hexdigest()}
    (out / "manifest.json").write_text(json.dumps(manifest, indent=2), encoding="utf-8")
    print(out)
    print(json.dumps({str(t): result["records"][t-60]["metrics"] for t in (139, 165, 239)}))
    print(result["invalid_eigenvalues"])


if __name__ == "__main__":
    main()

```

### 22.4.4 工程限制

完整样本协方差每次重算的主要成本为 $O(kp^2)$ ，特征值分解约为 $O(p^3)$ 。四资产很轻，但数千资产每条消息分解一次通常不合适；可降低计算频率、分组或使用低秩方法。

本例replay保存全部历史矩阵，内存随时间增加；没有生产状态持久化、事务恢复、并发服务或乱序接入。它假设上游已按同频、统一资产顺序输出收益，不能用本代码代替时间对齐模块。

dcc_step只保证在调用方提供合法目标与残差时执行给定递推；不负责检查完整GARCH拟合契约。shrink同样假定输入为有效样本协方差，不能当成任意矩阵的通用修复函数。

8项测试分别覆盖：与NumPy协方差交叉验证、奇异矩阵收缩、逐对反例、前缀重放、未来扰动、预测先于本期观测、缺失与正定性、DCC参数及零方差边界。

## 本章总结

协方差矩阵必须是共同可实现的整体。逐元素相关合法不保证整体半正定；统一样本、正定性检查和版本契约必须一起使用。

收缩改善条件数并控制估计噪声，但有偏差，不能替代金融解释。EWMA描述外积的指数更新，DCC进一步把条件波动与相关分层；预测和观察后更新必须区分。

尾部共振与网络集中度提供补充视角，但有限样本条件概率不是极限尾依赖，无向相关网络也不是因果传染图。

## 详细参考答案

### 题1

所有资产收益乘100，协方差乘10000；标准差各乘100，相关分子分母同倍变化而抵消。若只改变一列，相关仍不变，但该行列协方差缩放不同。组合权重通常是资金权重，不能补偿错误单位；必须统一后计算。

### 题2

任意w的二次型等于中心化组合收益平方和除以n−1，故非负。中心化矩阵的行和为0，秩最多n−1；再受列数p限制。5资产4观测时秩最多3，因此不可逆。可收缩或减少维度，但要报告方法。

### 题3

取v=(−1,1,1)，矩阵乘v得到−v，二次型为−3。三项两两关系无法在同一组单位向量中同时实现：A与B相同、A与C相同，应推出B与C相同，而非完全相反。逐对样本让它们看似同时成立。

### 题4

平均特征值为2，所以目标为2I。更新后：

```math
(0.75\times0+0.25\times2,
0.75\times1+0.25\times2,
0.75\times5+0.25\times2)
=(0.5,1.25,4.25).
```

条件数4.25/0.5=8.5。迹仍为6。原矩阵奇异，新矩阵正定。

### 题5

alpha=9/(9+1)=0.9。原均方误差9，收缩风险为 $0.1^2\times9+0.9^2\times1=0.9$ 。

随机目标与样本估计可能相关，交叉项未必为0，目标误差本身也随机；必须重新推导，不能沿用固定目标结论。

### 题6

外积为：

```math
uu^\top=
\begin{pmatrix}4&-2\\[0pt]-2&1\end{pmatrix}.
```

更新：

```math
H_{\mathrm{new}}=
\begin{pmatrix}1.3&-0.2\\[0pt]-0.2&1\end{pmatrix},
\qquad
\rho=-\frac{0.2}{\sqrt{1.3}}\approx-0.175412.
```

更新矩阵只能用于该观测之后的描述或下一期预测，不能回填为观察之前的预测。

### 题7

Q的对角线不固定为1，归一化后才是相关。对非零w，目标项贡献 $(1-a-b)w^\top\bar Qw\gt 0$ ，其他两项非负，所以总和严格正。

仅a+b小于1不足够：若a或b为负，非负组合证明失败；目标不正定或输入不有限也可能失效。

### 题8

### 题11

两资产等权且波动为sigma₁、sigma₂：

```math
\sigma_P^2
=\frac14\sigma_1^2+\frac14\sigma_2^2
+\frac12\rho\sigma_1\sigma_2.
```

当边际波动固定且为正，相关升高使方差增加；增加量为 $0.5\Delta\rho\thinspace \sigma_1\sigma_2$ 。但共同政策冲击或样本噪声也能改变相关，不能据此识别因果传染。
