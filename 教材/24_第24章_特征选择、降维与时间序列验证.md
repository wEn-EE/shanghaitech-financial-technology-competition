# 第24章 特征选择、降维与时间序列验证

> 本章仅使用SYNTHETIC人工序列。任务是预测未来三期人工因子的均值，用来检验时间验证机制，不是市场状态标准答案、真实收益预测成绩或交易策略。现有Anaconda与NumPy足够，无需安装依赖。

## 学习目标

先修线性代数、最优化、统计估计和第20—23章的PIT与特征工程。完成后应能区分三类特征选择；推导PCA的方差最大化、重建误差和SVD关系；推导岭回归；设计标签成熟约束、滚动验证与最终留出；解释特征稳定性、消融和多次试验偏差；实现每折独立拟合的完整流水线。

候选特征多并不意味着信息多。股价动量、技术指标和相关新闻可能重复表达同一冲击。需要选择的是在指定信息条件和用途下可靠的表示，而不是历史分数最高的一组名字。

## 24.1 过滤式、包裹式、嵌入式选择与PCA

### 24.1.1 先写任务，再谈重要性

状态识别回答现在处于什么状态，预测回答未来变量怎样变化，交易还需仓位、成本和执行。相同特征在三个任务中的价值不相同。用未来收益筛出的特征不能自动称为最好的危机状态解释变量。

先写明目标、决策时点、特征可用时间、标签区间、损失函数和部署资源。没有统一状态标签时，可以评价结构稳定性、经济可解释性和预警用途，但不能把某个聚类内部指标当作金融真值。

### 24.1.2 三类选择方法

**过滤式（Filter）**在主模型之外计算分数，例如方差、与标签的相关或互信息。计算便宜，但单变量评分可能漏掉交互。

对训练样本的Pearson相关，中心化后：

```math
\widehat\rho_j=\frac{\sum_i(x_{ij}-\bar x_j)(y_i-\bar y)}{\sqrt{\sum_i(x_{ij}-\bar x_j)^2}\sqrt{\sum_i(y_i-\bar y)^2}}.
```

分子是两个中心化向量内积，分母是长度乘积，故由Cauchy–Schwarz可得绝对值不超过1。常量列或常量标签使分母为0，不能把未定义当作强证据。

独立对称正负变量X1、X2的乘积Y=X1X2，与每个单变量可能不相关，却完全由两者联合确定；因此低线性相关不证明无信息。互信息可捕捉更广泛依赖，但有限样本估计、离散化和调参仍可能过拟合。

**包裹式（Wrapper）**反复训练模型比较特征子集，例如前向选择。p个特征的全部子集有2的p次方种，计算昂贵且验证集会被反复使用。

**嵌入式（Embedded）**在训练中选择或收缩特征，例如L1惩罚和树分裂。L1可能产生零系数，但相关特征之间可能不稳定地择一；L2通常不会产生精确零系数。树的重要性依赖分裂规则，也不能直接作为因果解释。

| 方法 | 主要优势 | 主要局限 |
|---|---|---|
| 过滤式 | 快，易审计 | 易漏交互，冗余可能同时入选 |
| 包裹式 | 对应具体预测器 | 计算与选择偏差较大 |
| 嵌入式 | 联合优化 | 依赖模型和正则化假设 |

删除常量、筛选相关、填补缺失都必须在每折训练集重新拟合。先对全样本选特征再切分，已经泄漏。[官方泄漏示例](https://scikit-learn.org/stable/common_pitfalls.html)

### 24.1.3 PCA：最大化投影方差

**主成分分析（Principal Component Analysis，PCA）**把原特征变换为正交线性组合。设训练数据中心化矩阵为X，形状n乘p，样本协方差为S=X转置乘X除以n−1。

投影到单位向量v后，得分为Xv，样本方差为：

```math
\frac{\lVert Xv\rVert^2}{n-1}=v^\top Sv.
```

第一主成分解：

```math
\max_v v^\top Sv\quad\mathrm{subject\ to}\quad v^\top v=1.
```

约束防止通过任意放大v虚增方差。构造Lagrangian：

```math
\mathcal L=v^\top Sv-\lambda(v^\top v-1).
```

对v求导，因S对称：

```math
2Sv-2\lambda v=0,\qquad Sv=\lambda v.
```

把v展开在S的正交特征向量基上，目标值是特征值的非负加权平均，权重和为1，因此最大值为最大特征值。后续方向加上与此前方向正交的约束，依次取剩余最大特征值方向。

载荷向量描述组合系数，得分是样本在方向上的坐标。两者不能混为“重要性”。[PCA官方说明](https://scikit-learn.org/stable/modules/decomposition.html#pca)

### 24.1.4 重建误差、SVD与尺度

取前k个特征向量组成V_k，列正交。投影和重建为：

```math
Z=XV_k,\qquad \widehat X=XV_kV_k^\top.
```

因为投影部分与残差正交，平方和可以分解：

```math
\lVert X-\widehat X\rVert_F^2
=\lVert X\rVert_F^2-\lVert XV_k\rVert_F^2
=(n-1)\sum_{j>k}\lambda_j.
```

因此保留最大特征值同时最小化线性正交重建误差。解释方差比例为：

```math
\mathrm{EVR}(k)=\frac{\sum_{j=1}^k\lambda_j}{\sum_{j=1}^p\lambda_j}.
```

若总方差为0，这个比例未定义。

对X做奇异值分解X=UDV转置，得到S=VD平方V转置/(n−1)，所以特征值等于奇异值平方除以n−1。直接SVD可避免先形成协方差导致条件数平方放大；大矩阵仍需考虑内存与近似求解误差。

金额和比例混合时，不标准化的PCA可能由单位尺度主导；标准化PCA则等价于对相关结构降维，但也会放大低方差噪声。标准化不是永远更优，必须服从业务口径。均值、尺度和载荷全部只从训练集取得，未来样本使用同一变换。

解释95%方差不等于解释95%预测能力。若目标依赖低方差方向，PCA可能恰好删除它。第一主成分也不天然叫作“风险偏好因子”，命名需要经济证据。

### 24.1.5 岭回归与坐标旋转

实验用**岭回归（Ridge Regression）**提供稳定、可解释的预测器。对中心化标签y和变换后矩阵Z，最小化：

```math
J(\beta)=\lVert y-Z\beta\rVert^2+\gamma\lVert\beta\rVert^2,\qquad\gamma>0.
```

展开后求导：

```math
\nabla J=-2Z^\top y+2Z^\top Z\beta+2\gamma\beta=0.
```

所以解满足：

```math
(Z^\top Z+\gamma I)\widehat\beta=Z^\top y.
```

正则项使左侧正定；程序求解线性方程，不显式求逆。截距由训练标签均值恢复且不惩罚。若损失换为平均平方误差，正则参数的对应尺度也要变化。

若保留全部主成分，只进行正交旋转，L2长度和拟合空间不变，所以同一惩罚下的预测应与未旋转版本一致。只保留部分成分则改变空间，可能降低噪声，也可能丢失信号。本章专门测试这一等价关系。

## 24.2 滚动验证、标签区间隔离与数据泄漏

### 24.2.1 可见特征与成熟标签

每个样本至少记录决策时刻t、特征ready、标签信息区间和label_ready。预测未来H期平均量时：

```math
y_t=\frac1H\sum_{j=1}^{H}f_{t+j}.
```

即使x_t在t已知，y_t也需未来数据。实验H=3，标签额外延迟一期，因此label_ready=t+4。

模型假设在验证起点v之前完成拟合，故训练样本必须满足：

```math
t<v,\qquad \mathrm{label\_ready}_t<v.
```

使用严格小于是本章边界协议。若允许同一时刻先接收标签再训练，必须给出明确事件顺序和真实计算延迟，不能随意改成小于等于。

验证起点80时，最后允许的训练样本是75，因为75+4=79；76的标签在80才可用，已晚于本章拟合截止。

### 24.2.2 扩展窗口与固定窗口

**扩展窗口（Expanding Window）**不断增加过去训练样本，信息多，但旧机制可能影响现在。**滚动窗口（Rolling Window）**只保留最近固定长度，可响应变化，但方差更大。

每折必须完整重拟合：质量过滤、缺失填补、缩放、筛选、PCA、预测器和阈值。Pipeline有助于封装，但不会自动修复错误的时间索引或上游未来特征。

TimeSeriesSplit的gap表示排除训练尾部的样本数，不是自动理解经济时间或标签终点。不等距新闻、不同预测期限和标签延迟应按实际时间字段筛选。[官方时间切分文档](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)

历史特征窗口与验证特征窗口共享过去行情，并不自动构成泄漏：在真实上线时，这些过去行情本来可见。需要禁止的是未来信息和不合时序的拟合，不是机械禁止一切原始数据重叠。

### 24.2.3 标签区间清除与隔离

**清除（Purging）**删除标签信息区间与验证标签区间重叠的训练样本。两个半开区间[a,b)、[c,d)重叠，当且仅当：

```math
\max(a,c)<\min(b,d).
```

边界是否闭合必须服从数据定义。未来标签跨越验证起点时，训练日期虽然早，也可能偷看验证时期。

**隔离期（Embargo）**通常指验证段之后不立即纳入训练的区段，用于某些含验证段之后训练样本的研究切分。本章严格只用过去训练，因此没有机械添加“验证后未来训练”；其核心约束是标签成熟和拟合截止。

清除、隔离不是万能药：无法修复全样本PCA、修订宏观数据回填、新闻全历史聚类或长期反复调测试集。也不能把训练包含未来的交叉验证伪装成真实前向部署。[滚动预测起点评估教材](https://otexts.com/fpp3/toolbox.html)

### 24.2.4 模型选择、嵌套验证和最终留出

候选方案在开发期的多个前向折上比较，选出方案后，在最终拟合截止前的全部合格样本重训，最后一次评价留出区间。开发折分数用于选择，不是选择后方案的无偏最终成绩。

若要评估整套调参程序，可使用**嵌套验证（Nested Validation）**：外层每个训练区间内部再做前向调参，外层未来区间只评价内层选定的程序。不能只把同一结果换个名字叫嵌套。

第24.4节采用三个开发折加一个最终留出。第24.5节另实现三组外层前向窗口，每组内部重新选择参数。预设候选为raw、pca1、pca2，均选两项原特征，岭参数固定1。看完最终结果后再增加候选，就需要新的未用留出区间。

## 24.3 特征稳定性、消融实验与选择偏差

### 24.3.1 稳定不等于有效

跨折入选频率反映算法选择是否一致；两个子集的Jaccard为交集大小除以并集大小。高度相关特征可相互替代，导致名字不稳定但预测稳定。反之，同一错误特征每次入选也可能非常稳定。

PCA的v与−v是同一方向，不应把符号翻转当作经济机制反转。相近特征值会导致单个向量大幅旋转，可比较投影矩阵V_kV_k转置或子空间夹角。特征值跨越截断边界时，子空间也可能不稳定。

监控原始分布、缺失覆盖、系数、子空间和预测性能，才能区分数据变化、表示变化与模型失效。

### 24.3.2 消融和置换重要性

**消融实验（Ablation Study）**移除某组特征后重新训练，比较相同时间区间的损失。删除宏观组时也应重拟合剩余流水线，否则比较的不是完整替代方案。记录是否给予相同调参预算。

**置换重要性（Permutation Importance）**固定模型，打乱特征后观察损失变化。它回答模型对该输入的依赖，不等于该变量的因果作用。相关特征可能相互补偿；逐行乱序破坏时间结构，应考虑按块、按事件或分组扰动，并说明改变了什么分布。[官方置换重要性说明](https://scikit-learn.org/stable/modules/permutation_importance.html)

若扰动产生现实不可能的股债和宏观组合，性能下降也可能来自分布外输入。不存在一项重要性指标可以替代经济解释。

### 24.3.3 反复试验和不确定性

在独立、每项误报概率为a的简化假设下，m次检验至少一次误报的概率为：

```math
1-(1-a)^m.
```

a=0.05、m=20时约64.15%。真实候选通常相关，该数值不能直接套用；它说明“试了很多次”必须记录。改变特征、窗口、标签和随机种子都属于研究试验。

相邻标签共享未来观测，损失差序列也可能相关。不能把240个重叠样本当作240次独立试验，直接报告普通独立标准误。可以在明确依赖条件下研究分块重采样或相关稳健推断，但不能用三个折就证明收益显著。

先固定验收指标，再报告每折、时期、覆盖和简单基线。没有真实金融标签时，最多声称程序验证通过和合成任务表现，不应声称金融泛化得到证明。

## 24.4 完整实验：每折拟合与成熟标签验证

### 24.4.1 机制与协议

人工因子满足f_t=0.85f_{t−1}+噪声，噪声标准差0.5，初始值0。每期五列为两个带小噪声的因子观测、两个无关噪声和一列常量。它们是用于验证方法的特征代理，不冒充真实多资产行情。目标为未来三期因子均值。

产生240个决策样本，特征在t可用，标签在t+4可用。三个开发验证段为80—99、120—139、160—179；最终留出200—239。模型分别在80、120、160、200之前完成，训练耗时假设0。最后一个测试标签在243可用，最终离线评价必须等到它成熟。

每折训练：删除训练常量列；用训练均值和样本标准差缩放；按训练绝对相关选两列；选择不降维、一维PCA或二维PCA；拟合岭回归。未来区间只能调用predict。

```python
"""SYNTHETIC temporal validation; existing NumPy only."""
from pathlib import Path
from datetime import datetime, timezone
import json
import hashlib
import numpy as np

HORIZON = 3

def data(n=240):
    rng = np.random.default_rng(20261115)
    f = 0.0
    states, rows = [], []
    for t in range(n + HORIZON):
        f = 0.85*f + rng.normal(scale=0.5)
        e = rng.normal(size=4)
        states.append(f)
        rows.append([f+0.1*e[0], f+0.15*e[1], e[2], e[3], 1.0])
    x = np.asarray(rows[:n])
    y = np.array([np.mean(states[t+1:t+HORIZON+1]) for t in range(n)])
    ready = np.arange(n) + HORIZON + 1
    return x, y, ready


def train_ids(ready, start):
    # Model fitting completes just before decision start (zero cost assumption).
    return np.flatnonzero((np.arange(len(ready)) < start) & (ready < start))


def fit(x, y, mode):
    if mode not in ('raw', 'pca1', 'pca2'):
        raise ValueError('unknown mode')
    if len(x) < 3 or not np.isfinite(x).all() or not np.isfinite(y).all():
        raise ValueError('invalid training data')
    mu = x.mean(axis=0)
    scale = x.std(axis=0, ddof=1)
    eligible = np.flatnonzero(scale > 1e-12)
    if len(eligible) < 2 or np.std(y) == 0:
        raise ValueError('need two variable features and variable target')
    scale = np.where(scale > 1e-12, scale, 1)
    z = (x-mu)/scale
    yc = y-y.mean()
    scores = np.abs(z[:, eligible].T @ yc) / (
        np.linalg.norm(z[:, eligible], axis=0)*np.linalg.norm(yc))
    order = np.argsort(-scores, kind='stable')[:2]
    selected = eligible[order]
    a = z[:, selected]
    _, singular, vt = np.linalg.svd(a, full_matrices=False)
    components = np.eye(2) if mode == 'raw' else vt[:int(mode[-1])].T
    transformed = a @ components
    ridge = 1.0  # Objective: summed squared error + ridge * ||beta||^2.
    beta = np.linalg.solve(transformed.T @ transformed + ridge*np.eye(transformed.shape[1]),
                           transformed.T @ yc)
    return {'mean': mu.tolist(), 'scale': scale.tolist(), 'selected': selected.tolist(),
            'components': components.tolist(), 'beta': beta.tolist(), 'intercept': float(y.mean()),
            'singular': singular.tolist(), 'mode': mode, 'ridge': ridge}


def predict(model, x):
    z = (x-np.array(model['mean']))/np.array(model['scale'])
    return z[:, model['selected']] @ np.array(model['components']) @ np.array(model['beta']) + model['intercept']


def select(x, y, ready):
    modes = ('raw', 'pca1', 'pca2')
    trials = []
    for mode in modes:
        folds = []
        for start in (80, 120, 160):
            tr = train_ids(ready, start)
            va = np.arange(start, start+20)
            m = fit(x[tr], y[tr], mode)
            loss = float(np.mean((predict(m, x[va])-y[va])**2))
            folds.append({'start': start, 'train_ids': tr.tolist(), 'validation_ids': va.tolist(),
                          'mse': loss, 'selected': m['selected']})
        trials.append({'mode': mode, 'mean_mse': float(np.mean([f['mse'] for f in folds])), 'folds': folds})
    winner = min(trials, key=lambda r: (r['mean_mse'], modes.index(r['mode'])))['mode']
    return winner, trials


def experiment(x, y, ready):
    winner, trials = select(x, y, ready)
    tr = train_ids(ready, 200)
    test = np.arange(200, len(y))
    model = fit(x[tr], y[tr], winner)
    pred = predict(model, x[test])
    baseline = float(y[tr].mean())
    return {'data_kind': 'SYNTHETIC', 'chosen': winner, 'trials': trials,
            'final_train_ids': tr.tolist(), 'test_ids': test.tolist(), 'model': model,
            'prediction': pred.tolist(), 'test_mse': float(np.mean((pred-y[test])**2)),
            'baseline_mse': float(np.mean((baseline-y[test])**2)),
            'persistence_mse': float(np.mean((x[test, 0]-y[test])**2)),
            'x': x.tolist(), 'y': y.tolist(), 'label_ready': ready.tolist()}


def main():
    result = experiment(*data())
    out = Path(__file__).parent/'runs'/datetime.now(timezone.utc).strftime('run_%Y%m%dT%H%M%S_%fZ')
    out.mkdir(parents=True)
    p = out/'results.json'
    p.write_text(json.dumps(result, indent=2, allow_nan=False), encoding='utf-8')
    manifest = {'numpy': np.__version__, 'code_sha256': hashlib.sha256(Path(__file__).read_bytes()).hexdigest(),
                'result_sha256': hashlib.sha256(p.read_bytes()).hexdigest()}
    (out/'manifest.json').write_text(json.dumps(manifest, indent=2), encoding='utf-8')
    print(out)
    print([(t['mode'], t['mean_mse']) for t in result['trials']])
```

## 24.5 综合实验：用第23章新闻与行情做嵌套前向验证

### 24.5.1 读入同一份数据，先核对两条时间线

第24.4节用独立人工因子验证数学和代码。本节直接读取第23.5节生成的 `fusion.json`。数据依然是SYNTHETIC。股票、债券、黄金和外汇是示例资产，新闻方向对价格漂移的影响由生成器预设。本实验的评价对象是未来三期简单收益的回归误差。市场状态识别和交易执行仍沿用各自的标签与评价契约。

以资产和决策时刻作为联合主键，一行特征与一行标签对应。读取之后先拒绝重复主键、标签缺行、特征时间晚于决策、标签结束早于或等于开始、标签成熟早于区间结束，以及与清单不一致的文本模型ID。程序还要求每个评价窗口都包含完整资产面板，避免删除一项难预测资产后让比较变好看。面板时间按决策时刻切，同一轮的四项资产一起移动，避免把同一时刻的一项资产放进训练、其余资产放进测试。

预测时核对feature_ready不晚于该行的decision_time。拟合又有一个独立条件，即label_ready严格早于拟合时点。例如45期样本的收益标签可能覆盖45到48期，行情刚好及时也只能在48期成熟，到48期外层拟合截止仍不合格。若标签在47期结束但报价延迟至48才可用，结果一样。特征已经可以预测和标签可以用于训练，是两个独立问题。这里的严格小于是教学协议，部署时还要把训练耗时和模型发布时间留出。

```math
\mathcal{T}(v)=
\lbrace i:t_i<v,\ a_i^y<v\rbrace.
```

其中 $t_i$ 是资产行的决策时刻， $a_i^y$ 是该行标签成熟时刻， $v$ 是拟合截止。程序也在读入时逐行检查特征时点。输入摘要记录实际文件字节，文本模型ID记录来源模型，二者承担不同职责。只收到一个注明ready的数值文件时，读入器无法独立证明其上游没有前视，应结合第23章的原始证据和前缀验证。

| 外层开始 | 内层验证区间 | 内层成熟训练行数 | 外层成熟训练行数 | 评价行数 |
|---:|---|---:|---:|---:|
| 48 | 28—33、36—41 | 4、36 | 84 | 64 |
| 64 | 44—49、52—57 | 68、100 | 148 | 64 |
| 80 | 60—65、68—73 | 132、164 | 212 | 64 |

内层预算对两组相同。保留特征数候选为1和2，岭系数候选为0.1、1和10，一共六组。内层两次验证各有24行，平均两折MSE等同于合并这48条误差平方再取均值。同分时优先少特征，其次使用较小岭系数，确保固定顺序。若未来改用不同长度窗口，等权按折与按行加权回答不同问题，应先定口径。一般嵌套验证文档强调外层用于评价调参过程，金融数据在此基础上还要把每一层改成时序切分，并检查标签成熟。[scikit-learn官方嵌套验证示例](https://scikit-learn.org/stable/auto_examples/model_selection/plot_nested_cross_validation_iris.html)

### 24.5.3 两组只改变候选信息，所有拟合保持对称

两组候选如下。

| 组别 | 初始列 |
|---|---|
| 仅行情 | 最近一期可用收益、报价年龄 |
| 行情加新闻 | 同样的行情列，再加入新闻分数、报道数、有分数报道数 |

最新一期收益可能因没有两条连续可用行情而缺失，用当前训练折中位数填补。训练中整列缺失时填0并由常量过滤移出候选。新闻分数未知时按预设填0，同时将报道数和有分数报道数提供为候选。这样原始数据仍可以区分“没有报道”和“已有报道但无法评分”。一旦筛选器只保留新闻分数，两类零值在这个模型里便会得到相同输入，应在覆盖分析中留意。部署时也可将计数和分数绑定选择，再按同样的内层预算重评。

设填补后的输入为 $x_{ij}$ ，在该训练折将列变换成均值0、总体式标准差1的 $z_{ij}$ 。常量列直接移出，其他列的平方和为训练行数n。标签中心化为 $y_i-\bar y$ 。对任意非恒定目标，Pearson绝对值的排序等价于下式的排序，因为所有候选的分母相同。目标恒定时得分全相同，模型中心化标签为0，输出训练均值。

```math
s_j=\left|\sum_{i=1}^n z_{ij}(y_i-\bar y)\right|.
```

取前k列，记矩阵为Z。24.1.5节使用误差平方和。本节用平均平方误差再加岭惩罚，所以候选正则系数的尺度也不同。求导后令梯度为0，转成如下方程求解。

```math
\left(\frac{Z^\top Z}{n}+\lambda I\right)\widehat w
=\frac{Z^\top(y-\bar y\mathbf{1})}{n}.
```

一个可手算的例子有三行，行情列依次为−1、1、缺失，目标为−2、2、0。中位数0填入第三行，列均值0，标准差为根号下2/3。设岭系数为1。标准化后设计列平方和除以3为1，因此方程左侧的系数为2，模型把无惩罚斜率缩为一半。换回原单位后斜率由2变1，预测为−1、1、0。测试同时放入全缺失的新闻列，确认它不会靠默认填补被选中。

两组在同一外层样本上配对比较。以零收益预测为额外基线。设第f折中有 $n_f$ 行，先对同一行计算误差平方差，再平均。负值表示该折加入新闻的候选流程误差更小。

```math
\Delta_f=\frac{1}{n_f}\sum_{i\in f}
\left[(\widehat y_{i,\mathrm{news}}-y_i)^2-(\widehat y_{i,\mathrm{market}}-y_i)^2\right].
```

这是允许两组分别选择参数的整体方案比较。若需要分辨“字面加入一列带来的变化”与“调参产生的变化”，可另做固定列、固定惩罚的预设对照，再保留这里的端到端比较。

## 详细参考答案

### 题1

任务目标不同。收益筛选依赖未来标签，状态识别要求解释当前结构，交易还依赖成本、仓位和约束。一个预测收益的变量可能难以解释状态，也可能交易成本过高。应分别定义损失与评价，不能跨任务转移“最优”结论。

### 题2

所有变量均值0，E[X1Y]=E[X1平方X2]=E[X2]=0，同理X2协方差0；两变量联合却精确决定Y。零单变量线性相关不证明没有交互预测信息。

### 题3

解释比例9/(9+1)=90%；重建误差为(n−1)乘剩余特征值1。若n=11则平方误差10。注意这是中心化训练数据的总平方误差，不是预测标签误差；若输入标准化，单位是标准化空间。

### 题4

展开平方项求梯度得(Z转置Z+gamma I)beta=Z转置y。对正交旋转V，令theta=V beta，则ZV beta=Z theta，且beta长度等于theta长度，目标函数一一对应，所以预测相同。截断主成分或改变惩罚方式会破坏该等价。

### 题5

t+4<80意味着t<76，最大整数75；从0至75共76条。若真实拟合耗时为2期且必须80前完成，则训练信息截止还需进一步前移，不能继续沿用零耗时结果。

### 题6

半开区间不重叠，因为max起点=15、min终点=15，不满足严格小于。若都闭合，共享时刻15；是否共享同一收益观测还需依据标签定义。必须先定义时间区间，再写清除代码。

```python
from validation_lab import data, experiment
x, y, ready = data()
a = experiment(x, y, ready)
x[200:] *= 100
y[200:] += 999
b = experiment(x, y, ready)
assert a['chosen'] == b['chosen']
assert a['model'] == b['model']
assert a['trials'] == b['trials']
```

预测值和最终误差可以改变，因为输入和真值已改变；不能要求它们也相同。该测试检验训练隔离，不检验模型本身是否有用。

### 题8

PCA比例取决于输入、尺度、窗口和协方差估计。高方差方向可能是价格水平或共同计价效应，极端损失也可能藏在低方差方向。需经济解释、尾部分析和独立未来评价，不能把几何方差比例改名为全面风险覆盖。

### 题9

1−0.95的20次方约0.641514。它基于独立、每项误报概率确为0.05；候选相关时不可直接套数。仍需记录研究次数、保留最终留出，并选择符合依赖结构的多重检验或评估方案。

### 题10

按价格、宏观、文本、跨资产结构预先定义组；各消融版本用相同外层未来区间和相同调参预算。每个外层训练段内部重新做前向选择，外层只评估。记录所有候选、标签成熟时刻、训练索引、数据快照、特征版本、变换参数和模型完成时刻。

验收包括：未来扰动不改过去模型；未成熟标签不能进入；全样本缩放反例被检查阻止；同一模型按完整快照可重建；缺失、常量、资产重排和部署输入版本不匹配可识别。评分建议时间边界30、数学正确25、公平比较20、审计和故障15、成本10。测试集最好看但无法复现不能通过。
