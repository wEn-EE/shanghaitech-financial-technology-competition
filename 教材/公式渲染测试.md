2026-10-23 用户截图中，前一版集合公式报错时显示为 `\left{`，而文件原文为 `\left\{`；这与花括号转义在渲染前被处理的情况一致。现改用明确的括号命令 `\left\lbrace` 与 `\right\rbrace`，不再依赖 `\{`、`\}` 的转义传递；用户已于 2026-10-23 确认此修订在 GitHub 正常。
