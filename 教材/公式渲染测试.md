本页用于对比 VS Code 内置 Markdown 预览与 GitHub 文件预览。请查看渲染后的页面，而不是源码或 Raw 页面。前六章已据此恢复数学排版。

## 1. 行内公式：单美元符号

资产价格为 $P_t$ ，简单收益率为 $r_t = (P_t - P_{t-1}) / P_{t-1}$ 。

若所有 $c_i = 0$ 才能使线性组合等于零，则这组向量线性无关。

统一留空格：变量 $x^2$ 表示 x 的平方。

2026-10-23 用户截图确认：公式外侧留空格的版本正常，紧贴中文的版本未被识别。后续写作统一在行内公式与相邻文字之间留空格；美元符号内侧不额外加空格。

预期：美元符号消失，t 和 i 显示为下标，2 显示为上标。

## 2. 独立公式：双美元符号

判断线性无关时使用的等式是：

$$
\sum_{i=1}^{k} c_i v_i = 0
$$

预期：公式独立成行，求和符号及其上下限正常显示。

## 3. 分式与根号

当 n 大于 1 时，样本标准差为：

$$
s = \sqrt{\frac{1}{n-1}\sum_{i=1}^{n}(r_i-\bar{r})^2}
$$

预期：分子和分母上下排列，根号覆盖整个被开方表达式。

## 4. 截图中的张成空间与秩公式

用户实测：此前的 operatorname 写法在 VS Code 中正常，在 GitHub 上提示该宏不允许使用；同页 mathrm 对照公式在 GitHub 上正常。以下两式改用 mathrm，保留数学排版：

$$
\mathrm{span}(v_1,\ldots,v_k) = \left\lbrace \sum_{i=1}^{k} c_i v_i : c_i \in \mathbb{R} \right\rbrace
$$

$$
\mathrm{rank}(M) + \dim \mathcal{N}(M) = n
$$

预期：span 和 rank 显示为直立字形；集合花括号保留；不出现宏命令错误。

2026-10-23 用户截图中，前一版集合公式报错时显示为 `\left{`，而文件原文为 `\left\{`；这与花括号转义在渲染前被处理的情况一致。现改用明确的括号命令 `\left\lbrace` 与 `\right\rbrace`，不再依赖 `\{`、`\}` 的转义传递；用户已于 2026-10-23 确认此修订在 GitHub 正常。

这里的替换适用于这两处名称后接括号的表达式。mathrm 负责直立字体，不具备 operatorname 的全部算子间距和上下限行为；其他公式不能不加区分地机械替换。

## 5. 矩阵

两项资产的协方差矩阵可以写成：

$$
\Sigma = \begin{pmatrix}
\sigma_1^2 & \rho\sigma_1\sigma_2 \\
\rho\sigma_1\sigma_2 & \sigma_2^2
\end{pmatrix}
$$

预期：矩阵显示为两行两列，左右有放大的圆括号。

## 6. 多行推导与等号对齐

简单收益率的等价表达为：

$$
\begin{aligned}
r_t &= \frac{P_t-P_{t-1}}{P_{t-1}} \\
    &= \frac{P_t}{P_{t-1}}-1.
\end{aligned}
$$

预期：推导分为两行，两个等号竖直对齐。
