# 数学公式阅读约定

本教材采用不依赖数学插件的 Markdown 排版。行内记号放在行内代码中，独立推导放在 `text` 等宽文本块中。普通 Markdown 阅读器即可显示，不需要 MathJax、KaTeX 或 LaTeX 宏支持。

这些文本块是数学表达式，不是可直接执行的 Python 代码。数值计算程序另用 `python` 代码块标明。

## 常用记号

|写法|含义与阅读方式|
|---|---|
|`x_i`、`x_(t-1)`|下标，分别表示第 i 个分量和 t−1 时刻的值；复杂下标用括号界定|
|`x^2`、`x^(n-1)`|乘方；这里的 `^` 不是 Python 的按位异或操作|
|`M^T`、`M^(-1)`|矩阵转置、矩阵逆|
|`((a+b) / (c+d))`|整个 a+b 除以整个 c+d；分子、分母的括号保留运算范围|
|`sqrt(x)`|x 的平方根；平方根包含的全部表达式写在括号内|
|`∑_(i=1)^n a_i`|i 从 1 到 n 的求和；没有上下限时由本节上下文规定索引范围|
|`∏_(i=1)^n a_i`|i 从 1 到 n 的连乘|
|`∫_a^b f(x) dx`|从 a 到 b 的积分|
|`x̄`、`μ̂`、`X̃`|上横线、上尖帽与波浪线；具体含义在本章定义，常用于均值、估计量和变换后的量|
|`widehat(SE)`|在多字符 SE 上加估计帽，表示标准误估计；不是遗漏的函数实现|
|`ℝ`、`𝔼[X]`|实数集合、随机变量 X 的期望|
|`𝒩(M)`、`𝒞(M)`|第3章的零空间、列空间；花体字母与普通字母按上下文区分|
|`ℱ_t`|第5章开始使用的时刻 t 的信息集|
|`𝟏`|按上下文表示全1向量；`𝟏{条件}`表示条件成立时为1的指示函数|
|`≤`、`≥`、`≠`、`≈`|小于等于、大于等于、不等于、近似等于|
|`‖x‖_2`|向量的二范数；绝对值使用单竖线，范数使用双竖线|
|`C(n, k)`|组合数：从 n 个对象中选择 k 个的方法数|
|`→[P]`、`→[d]`|依概率收敛、依分布收敛|
|`~[iid]`|独立同分布于其后的分布|

## 矩阵与分段函数

矩阵用外层方括号表示整体，每个内层方括号是一行，分号分隔各行。例如：

```text
M = [[1, 2]; [3, 4]]
```

这是一个2行2列矩阵：第一行为 `[1, 2]`，第二行为 `[3, 4]`。列向量写作 `[[x_1]; [x_2]]`，一行向量写作 `[[x_1, x_2]]`，两者不能混淆。

分段函数直接写出条件：

```text
M_(t,a) = 分段{ 1，当 R_(t,a) 有效；0，否则 }
```

矩阵因子的标注改成分别定义，避免把括注误读为参与计算的符号：

```text
M = L U
L = [[1, 0]; [2, 1]]
U = [[2, 1]; [0, 1]]
```

## 示例：张成空间与秩

```text
span(v_1, …, v_k) = { ∑_i c_i v_i : c_i ∈ ℝ }
rank(M) + dim 𝒩(M) = n
```

`span` 表示所有线性组合构成的集合，`rank` 表示秩，`dim` 表示维数。字母和希腊符号的金融含义仍以各章定义为准。

## 维护原则

后续章节直接按上述记法写作，不再依赖美元分隔符或数学渲染宏。分式必须标明分子、分母的完整范围；长推导允许分多行写；矩阵必须保留行列顺序。已有 Python、SQL 等程序代码不作数学排版转换。

第1—6章的原数学源式可从 Git 历史中查询。`tools/markdown_math.py` 是本次格式迁移的维护工具，只支持本书已检查过的语法子集，遇到未知命令会报错，不是通用 LaTeX 转换器。
