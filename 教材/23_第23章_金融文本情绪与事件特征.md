# 第23章 金融文本情绪与事件特征

> 全部实验新闻为SYNTHETIC人工句子，不来自真实公司或赛题。时间为人工整数时钟。词典和规则用于说明数据契约，不代表中文金融情绪识别的有效成绩。本章不下载模型、不安装依赖。

## 学习目标

先修第17—20章的数据版本、清洗、时间对齐与PIT，以及第21章的特征聚合。完成后能够区分文本语气、事件事实、资产影响和未来收益；设计带原文证据的文本记录；推导词典分数、TF-IDF、分类损失和衰减聚合；构造可追溯的新闻特征；检验转载、迟到、更正和撤回的时间行为。

文本不是直接可加总的数字。平台必须先回答“谁在什么时间说了什么、针对哪个实体、依据哪一版原文”，再讨论模型给多少分。

## 23.1 新闻去重、实体解析与文本时间戳

### 23.1.1 文档、报道和事件不是同一个对象

**文档（Document）**是一份具体文本及其版本；**报道簇（Story Cluster）**是一组讨论相同消息的文档；**事件（Event）**是发生或被声称发生的经济行为。十家网站转载一次公告，不等于发生十次违约；同一篇报道也可能同时包含业绩、融资和诉讼三个事件。

建议分别保存document_id、source_id、story_id和event_id。真实系统不能假定上游天然给出准确事件簇。本章人工提供story_id，只测试已知簇下的去重，不把它称为自动新闻聚类。

原始层保存标题、正文、来源、原始URL或授权标识、抓取批次、内容哈希及语言。派生层保存解析文本、清洗版本、实体、证据区间、模型版本和运行完成时刻。原文不覆盖，删除广告等清洗也要记录；否则证据偏移可能再也无法定位原文。

### 23.1.2 五种时间和一个必要筛选顺序

事件发生时间event_time、首次发布时间published、系统接收时间received、文本处理完成时间ready，以及修订发布时间应分别记录。事件可以是预定的未来会议，所以不能普遍要求事件时间早于发布时间。系统可用时间应由可信处理日志确定，而不是接受供应商随意回填。

决策截止时刻为 $T$ 时，可用派生记录集合为：

```math
\mathcal D_T=\lbrace d:a_d\leq T\rbrace,
\qquad a_d=\max(t_{\mathrm{received},d},t_{\mathrm{ready},d}).
```

程序先筛可用版本，再在每个来源的报道链内选最新版本。反过来先选全历史最新版，会把未来更正泄漏到过去，或错误删除过去当时存在的旧稿。

本实验用available合并接收与完成时间，假设规则在时刻0就绪、推理耗时0；这不能替代真实上线的各阶段日志。整数时钟只是为了让边界可手算。

### 23.1.3 精确去重、近似去重与冲突证据

精确去重可以使用文本哈希：相同规范化文本得到相同摘要，但原文必须保留。哈希解决内容身份，不解决报道是否真实。不同措辞的转载需要近似匹配。

将文本转为字符n-gram集合A、B，Jaccard相似度为：

```math
J(A,B)=\frac{|A\cap B|}{|A\cup B|}.
```

它度量共享片段比例。两集合都为空时不应自动认定两篇未知文本相同，应单独处理。字符片段可减少中文分词依赖，却容易把仅数字或否定词不同的重要更正误合并。

向量表示也可用余弦相似度：

```math
\cos(x,y)=\frac{x^\top y}{\lVert x\rVert\lVert y\rVert}.
```

零向量无定义。相似度阈值应在训练/验证区间确定，不能看到测试期聚类效果再调整。

线上分簇只使用当时已经到达的文本。未来一篇综述不能反过来改变过去的簇和当时的新闻数量。需要重聚类时，产生新的历史研究版本，保留旧在线快照。

“去重”和“冲突消解”也不同：两家来源分别称已违约与未违约，应保留冲突及出处；不能只留下自己偏好的说法。

### 23.1.4 实体解析与资产映射

**命名实体识别（Named Entity Recognition，NER）**识别公司、机构、人物等文本片段；**实体链接（Entity Linking，EL）**将片段映射到唯一实体；资产映射再把实体关联到股票、债券、行业或币种。

公司简称可能重名，名称可能变更，母公司与子公司也不是同一法律主体。映射表应带有效区间、可用时间、来源和置信状态。不能利用未来证券代码或未来公司关系回填过去。

同一能源涨价消息，对生产商可能有利、对航空公司成本可能不利。不能把文档整体正负直接复制给所有被提及的资产。关系应是“文档—事件—受影响实体—资产—作用渠道”。无法确定时保留UNKNOWN。

## 23.2 金融情感、事件类型和证据抽取

### 23.2.1 标注对象决定任务

**情感分析（Sentiment Analysis）**在这里指对给定目标和标注口径判断文本倾向。至少区分：作者语气、公司经营含义、事件方向、投资者风险偏好及未来收益标签。

“亏损收窄”含负面词但经营状况改善；“盈利增长低于预期”同时包含增长与失望；“未发生违约”是否定事件，不等价于强烈利好。利率下降对不同债券久期、银行息差和汇率的影响也不相同。

Loughran与McDonald指出通用词表在金融文本中可能误判词义，说明领域词典需要独立验证。[2011年论文摘要与书目](https://onlinelibrary.wiley.com/doi/10.1111/j.1540-6261.2010.01625.x)

标注规范应明确目标实体、时间范围、事实/预测/传闻、正负中性与无法判断的区别。两人独立标注后记录分歧，不能用价格事后涨跌裁决一句文本“真实情绪”。若目标就是价格反应，应另建预测任务与标签时间窗。

### 23.2.2 词典基线、否定与未知

设正负词条命中数为P、N，最简单分数为：

```math
s=\frac{P-N}{P+N},\qquad P+N>0.
```

因为 $|P-N|\leq P+N$ ，分数在−1至1之间。P=3、N=1时s=0.5。没有命中应返回未知，而不是0；0还可能表示正负证据抵消。平台必须同时存命中量、覆盖和状态。

否定不宜一律翻转极性：“不差”可能较正面，“没有盈利增长”不等于确认亏损，“未违约”更不等于高信用。本章保守地抑制被短距离否定或不确定词修饰的词条，不将其反向计分。

中文没有天然空格分词。词典匹配有重叠、词边界和作用域问题。实验词条不重叠，使用字面匹配；前3字窗口只是演示规则，会在跨分句、双重否定和长距离修饰上失败，应作为明确已知局限。

### 23.2.3 TF-IDF与线性分类为何仍值得建立

**词频—逆文档频率（Term Frequency–Inverse Document Frequency，TF-IDF）**通过降低常见词影响来构造文本向量。取训练语料共N篇、包含词j的篇数为df_j，采用一种平滑定义：

```math
\mathrm{idf}_j=\log\frac{N+1}{\mathrm{df}_j+1}+1,
\qquad x_{dj}=\mathrm{tf}_{dj}\mathrm{idf}_j.
```

若词出现在所有训练文档中，idf=1；若仅出现在少量文档中，权重更高。这是定义选择，不是唯一自然定律。可再进行L2归一化，零向量需单独处理。词表、df和归一化策略只能在训练期拟合。[scikit-learn文本特征文档](https://scikit-learn.org/stable/modules/feature_extraction.html#text-feature-extraction)

对K类线性分类器，令 $z_k=w_k^\top x+b_k$ 。softmax将任意实数分数转成非负且和为1的量：

```math
p_k=\frac{e^{z_k-m}}{\sum_j e^{z_j-m}},\qquad m=\max_j z_j.
```

减去m不改变比例，却避免大指数溢出。真实标签为y的单样本负对数似然为：

```math
\ell=-\log p_y=-z_y+\log\sum_j e^{z_j}.
```

对某个logit求导：

```math
\frac{\partial\ell}{\partial z_k}=p_k-\mathbf1(k=y),
\qquad
\frac{\partial\ell}{\partial w_k}=(p_k-\mathbf1(k=y))x.
```

第一步来自log-sum-exp的导数，第二步使用链式法则。误差推动正确类分数上升、错误类分数下降。加入L2惩罚后还会增加相应权重梯度。这里解释后续监督模型接口；本章没有用7条人工新闻训练分类器或报告准确率。

### 23.2.4 上下文模型与概率解释

金融预训练模型可利用上下文，但仍受语言、来源和训练目标限制。ProsusAI的FinBERT模型卡标为英语金融情绪分类，不能直接认定适合中文公告；同名FinBERT也不一定是同一个模型。使用时冻结具体仓库修订、分词器、标签映射、最大长度和许可证。本次查看的模型卡列出使用许可条件，应按实际版本核对，不能假定所有金融模型可任意商用。[模型发布方说明](https://huggingface.co/ProsusAI/finbert)

若分类概率为负面0.6、中性0.3、正面0.1，可定义带符号摘要s=0.1−0.6=−0.5。它是标注类别上的摘要，不是下跌概率，也不是预计收益−50%。

softmax输出不自动校准。训练目标、样本失衡和来源变化均可能导致过度自信。可以在独立时间验证集上校准，再评估未来区间的可靠性；不能在最终测试集调温度或阈值。

### 23.2.5 事件结构与证据范围

事件记录至少包括类型、主体、客体、数值、单位、发生时间、陈述状态和原文证据。例如“公司计划发行10亿元债券”应抽取融资计划、发行主体、10亿元、计划而非已完成；不应生成“已融资10亿元”。

证据保存半开区间[start,end)和文本哈希，满足原文切片等于证据。Python字符串索引按Unicode码点；浏览器常用UTF-16偏移，字节存储又可能用UTF-8。跨服务传递时必须写明坐标体系，不能直接混用。

数字抽取必须区分百分比、百分点和基点；实体否定、条件句、引述对象也应保留。大语言模型可以输出候选结构，但字段必须有证据；缺乏证据时置空，不能为了JSON完整而补造事实。原文中的命令只作为新闻内容，不得控制系统工具或检索权限。

本章程序输出词条证据和否定标记，不实现通用事件抽取。规则、线性模型和上下文模型分别适合解释性基线、有限标注基线与复杂语境；比较时必须使用同一时间划分和标签规范。

## 23.3 舆情聚合、传播延迟与价格特征融合

### 23.3.1 时间衰减与有效权重

对截至T可用且有有效分数的文档，设置半衰期h：

```math
w_d(T)=q_d\exp[-\log(2)(T-a_d)/h],\qquad h>0.
```

q为事前定义的非负来源/相关性权重，不能根据未来预测成功率临时修改。间隔h后指数多出−log(2)，故权重减半。本章q=1。

聚合分数和质量量分别为：

```math
S_T=\frac{\sum_d w_d s_d}{\sum_d w_d},
\qquad M_T=\sum_d w_d.
```

分母为0时S未知。只看S会遗漏证据变旧：若没有新消息，所有权重同时衰减，分子分母同比变化，S不变，但M下降。因此必须同时显示质量量、更新年龄和消息数。

权重有效数量可写为：

```math
n_w=\frac{(\sum_d w_d)^2}{\sum_d w_d^2}.
```

由Cauchy–Schwarz，n_w不大于参与加权的篇数；非负权重下至少为1。它只衡量权重集中程度，不是独立新闻数量，也不自动提供正确标准误。转载和共同事件会进一步造成依赖。

### 23.3.2 转载、修订和撤回的聚合政策

本章依次执行：按可用时间筛选；每个story/source选最高已知修订；剔除该来源的撤回；同story、同文本哈希只保留最早可用的当前来源版本；最后聚合。

这种政策防止完全相同转载重复计数，但不同措辞仍可能多计。同一来源撤回不会自动撤回另一个来源的转载。实验故意保留这种情况，提示生产系统需要来源关系图、全局撤回政策和冲突提示，而不是默认“撤回传播已解决”。

如果保留的首发被撤回，转载可能成为代表，代表可用时间会改变。这是本例规则的后果；需要保持事件首次见到时间时，应另存不可变first_seen，并明确衰减使用哪种时间，不能悄悄更换口径。

### 23.3.3 与行情融合不等于因果识别

在决策时刻T做as-of连接，只使用ready不晚于T的文本和行情特征。延迟应同时报告“事件至发布”“发布至接收”“接收至特征完成”，负延迟或极端值须检查。

已发布但系统尚未接收的消息，不能用于本系统历史在线回放；可以单独作为理想信息实验。新闻可能是对价格变化的事后报道，新闻分数与收益相关不证明新闻导致价格变化。

若未来收益标签覆盖[T,T+H]，相邻样本标签可能重叠。按时间切分时，应处理跨分界标签区间，且同事件转载不能随机散落训练和测试。第24章系统讨论隔离间隔及时间验证。

### 23.3.4 评估和上线监测

分类精确率为TP/(TP+FP)，召回率为TP/(TP+FN)，F1为二者调和平均。某类分母为0时必须公开处理约定，不能偷偷删除困难类别。多类任务应报告逐类结果、宏平均、混淆矩阵、拒判率及各来源覆盖。

事件抽取还需评估实体链接、类型、数值单位、证据区间和陈述状态。只评估“是否找到关键词”不代表完整事件正确。

标注一致率可用Cohen kappa辅助：

```math
\kappa=\frac{p_o-p_e}{1-p_e},
\qquad p_e=\sum_k p_{A,k}p_{B,k}.
```

p_o是实际一致比例，p_e由两位标注者各类别边际比例计算。类别极不平衡时kappa的解释要谨慎，它不是金融正确性的证明。将分歧样本单独复核比只报告一个系数更有用。

生产监控至少包括来源中断、语言变化、未知率、文本长度、实体未链接率、重复率、证据不匹配率和推理延迟。与模型精度相比，数据契约失效通常应更早阻断服务。

## 23.4 完整实验：可追溯新闻特征回放

### 23.4.1 人工输入和预期

7个不可变版本覆盖盈利增长、亏损扩大、未违约、完全转载、迟到、修订和来源撤回。所有文本均映射到EQ_DEMO，仅示范接口；没有声称真实公司已发生这些事件。规则固定在时刻0，只依赖Python标准库。

4时无新闻；10时有3条去重记录，其中“未违约”未知，只有两条参加分数。12时迟到的旧事件首次可用，15时更正生效，18时首发来源撤回而另一来源转载仍保留。

```python
"""SYNTHETIC, deterministic news features. Python standard library only."""
from dataclasses import dataclass, asdict, replace
from pathlib import Path
from datetime import datetime, timezone
import hashlib
import json
import math
import re

RULE_VERSION = 'synthetic-lexicon-v1'
LEXICON = {'盈利增长': 1, '业绩改善': 1, '亏损扩大': -1, '违约': -1}

@dataclass(frozen=True)
class News:
    id: str
    story: str
    revision: int
    event_time: int
    published: int
    available: int
    source: str
    asset: str
    text: str
    withdrawn: bool = False


def classify(text):
    evidence = []
    # Three-character lookback is deliberately limited, not general negation parsing.
    for phrase, polarity in LEXICON.items():
        for m in re.finditer(re.escape(phrase), text):
            prefix = text[max(0, m.start()-3):m.start()]
            uncertain = any(x in prefix for x in ('可能', '传闻'))
            negated = any(x in prefix for x in ('未', '没有', '否认'))
            evidence.append({'start': m.start(), 'end': m.end(),
                             'text': m.group(), 'polarity': polarity,
                             'negated': negated, 'uncertain': uncertain})
    active = [e['polarity'] for e in evidence if not e['negated'] and not e['uncertain']]
    score = sum(active)/len(active) if active else None
    return {'score': score, 'evidence': evidence,
            'status': 'SCORED' if active else 'UNKNOWN',
            'rule_version': RULE_VERSION}


def snapshot(news, cutoff, asset, half_life=10):
    if half_life <= 0:
        raise ValueError('half_life must be positive')
    if len({n.id for n in news}) != len(news):
        raise ValueError('duplicate input id')
    latest = {}
    for n in news:
        if n.available < n.published or n.revision < 1:
            raise ValueError('invalid chronology or revision')
        if n.available > cutoff:
            continue
        key = (n.story, n.source)
        rank = (n.revision, n.available, n.id)
        if key not in latest or rank > (latest[key].revision, latest[key].available, latest[key].id):
            latest[key] = n
    chosen = {}
    for n in latest.values():
        if n.withdrawn or n.asset != asset:
            continue
        digest = hashlib.sha256(n.text.encode('utf-8')).hexdigest()
        # Known synthetic story IDs, not a learned clustering system.
        key = (n.story, digest)
        if key not in chosen or (n.available, n.id) < (chosen[key].available, chosen[key].id):
            chosen[key] = n
    details = []
    numerator = denominator = sum_sq = 0.0
    for n in sorted(chosen.values(), key=lambda n: n.id):
        pred = classify(n.text)
        weight = 2 ** (-(cutoff-n.available)/half_life)
        details.append({'id': n.id, 'weight': weight, **pred})
        if pred['score'] is not None:
            numerator += weight*pred['score']
            denominator += weight
            sum_sq += weight**2
    return {'cutoff': cutoff, 'asset': asset, 'documents': details,
            'unique_count': len(details),
            'scored_count': sum(d['score'] is not None for d in details),
            'sentiment': numerator/denominator if denominator else None,
            'weighted_mass': denominator,
            'weight_effective_count': denominator**2/sum_sq if sum_sq else 0,
            'rule_version': RULE_VERSION}


def sample():
    return [
        News('a1', 'A', 1, 1, 2, 5, 'wire', 'EQ_DEMO', '甲公司盈利增长。'),
```

10时正面文档权重为2的−0.5次方，负面为2的−0.2次方，所以近期负面获得更大权重。14时加入迟到正面；16时更正替换同来源旧负面，全部有效词条分数为正。20时分数仍为1，不表示新闻新鲜程度不变。

### 23.4.4 工程局限与改造

snapshot每次扫描全部输入，时间复杂度约O(N+U log U)，U是去重后的记录数；重复多次查询会重复计算。线上可按来源版本链索引、维护候选代表和累积量，但删除与修订必须撤销旧贡献，不能只做加法。

示例没有处理接收乱序的持久恢复、可靠全局事件聚类、长文句法、来源质量学习或事件级纠错传播。asset和story由人工给定。新版本的修订序号要求来源提供可信单调语义，id排序只是确定性平局规则；生产中冲突版本应隔离。

未来非法记录会使本实现整体校验失败：前缀不变性断言限定于通过输入契约的日志。部署时应将入口验证与历史查询隔离，坏消息进入隔离区，避免一条新坏消息阻断所有旧快照服务。

## 本章总结

文本进入平台前必须保留身份、时间、版本和证据。情绪不是价格预测，事件被否定也不是正面事实。词典建立可解释基线，TF-IDF和分类模型提供可学习表示，但所有拟合和阈值都服从时间划分。聚合必须同时报告分数、质量量、覆盖和年龄；修订与撤回只能在其可用之后改变状态。

## 详细参考答案

### 题1

文档是文本版本，报道簇是相关文档集合，事件是经济行为或其声称。十次转载可以是10个文档、1个报道簇、1个事件。统计传播热度时可保留转载量，统计独立消息时应去重；两者不是相同特征。

### 题2

(3−1)/(3+1)=0.5；没有命中应UNKNOWN，不能强行输出中性0。由非负P、N，−(P+N)不大于P−N且P−N不大于P+N，除以正分母得范围。P=N=2则分数0但存在正负证据，须与无信息区分。

### 题3

idf=log(10/5)+1=log2+1，约1.693147。测试文本只应用冻结词表和idf，未知词按既定规则处理。若线上更新词表，应生成新版本，只用于之后输出，而不覆盖旧评估。

### 题4

梯度为(0.2−1,0.8−0)=(−0.8,0.8)。损失−log0.2约1.609438。梯度下降使第一类logit升高、第二类降低。权重梯度还要分别乘输入向量；不能把logit梯度直接当作权重更新。

### 题5

可用时间为max(9,11)=11，10时不能用。4时发布只是公众可见的可能起点，不证明系统当时已取得并完成解析。11时边界按不大于截止的协议可用。

### 题6

两权重约0.707107和0.870551，分数为(0.707107−0.870551)/(0.707107+0.870551)=−0.103599。无新消息10期后权重均减半，归一分数不变，总权重减半。若设置有限窗口，消息过期还会改变参与集合，不能沿用不变结论。

### 题7

p_o=0.8，p_e=0.5平方加0.5平方=0.5，kappa=(0.8−0.5)/(1−0.5)=0.6。两人可能共同误解标签，故一致率不是相对真值的准确率。

### 题8

在code/ch23目录执行：

```python

from news_lab import sample, snapshot
x = sample()
old = snapshot(x, 10, 'EQ_DEMO')
x[5] = replace(x[5], text='未来更正内容不同。')
assert snapshot(x, 10, 'EQ_DEMO') == old
ids = [d['id'] for d in snapshot(x, 20, 'EQ_DEMO')['documents']]
assert 'a1' not in ids and 'copy' in ids
```

b2在15时才可用，不影响10。a2只撤回wire来源的A报道链，portal的copy没有撤回版本。若业务要求联动撤回，应建立可审计的来源关系和政策，而不是悄悄删除copy。

### 题9

降息的含义依赖预期、增长背景和资产渠道；亏损收窄描述改善但仍亏损；未违约否定某事件，不保证经营或信用良好。应标目标实体、事件方向、否定/事实状态、相对预期和证据，无法确定影响时拒判。

### 题10

请求包含原文快照、语言、来源、知识截止及目标实体；响应包含实体链接、事件类型、陈述状态、数值单位、证据坐标体系、模型版本与完成时刻。无证据字段为null，冲突来源并存。按时间及事件簇分割数据，报告逐类F1、事件字段正确率、未知率与延迟；用迟到、更正、撤回和服务重启做重放验收。入口坏数据隔离，保留原始投递和错误码。
