## 21.1 训练期标准化、归一化与稳健缩放

### 21.1.1 特征首先是一份契约

**特征（Feature）**是用于描述样本的数值或类别属性。比如“波动率”还不是完整特征定义，因为没有说明收益口径、窗口长度、缺失处理和计算时点。

一个合格特征至少记录：

| 内容 | 示例 |
|---|---|
| 输入与单位 | 已完成价格区间的简单收益，小数单位 |
| 业务频率 | 固定一分钟，或固定一个交易日 |
| 窗口 | 最近5个连续收益，需要6个连续价格 |
| 端点 | 包含当前已完成区间，不包含未来区间 |
| 统计约定 | 样本标准差，分母为4 |
| 缺失策略 | 窗口出现缺失则输出空值 |
| 可用时间 | 不早于所有输入及计算产物就绪 |
| 版本 | feature_code、参数、主数据及缩放器版本 |

**特征工程（Feature Engineering）**包括定义、计算、变换和验证这些属性。它不是尽可能多地调用指标函数。

同一个数值变换用于“状态描述”和用于“预测下一期收益”时，其计算可以相同，但样本对齐不同。收盘后计算的当日收益可描述当天已发生的状态，却不能在当天开盘时使用。

### 21.1.2 训练期标准化及其恒等式

**标准化（Standardization）**通常指减去位置参数，再除以尺度参数。

给定一个特征在训练集中的合格值 $x_1,\ldots,x_n$ ，定义：

```math
\mu=\frac1n\sum_{i=1}^n x_i,
\qquad
s_0^2=\frac1n\sum_{i=1}^n(x_i-\mu)^2,
\qquad
z_i=\frac{x_i-\mu}{s_0}.
```

这里假设 $s_0\gt 0$ 。分母采用 $n$ ，是把训练数据本身缩放为单位二阶中心矩，不是在此处估计总体方差的无偏估计量。

验证中心：

```math
\frac1n\sum_i z_i
=\frac{\sum_i x_i-n\mu}{ns_0}
=0.
```

验证尺度：

```math
\frac1n\sum_i z_i^2
=\frac{\sum_i(x_i-\mu)^2}{ns_0^2}
=1.
```

如果用分母 $n-1$ 的样本标准差 $s_1$ ，则：

```math
s_1^2=\frac{n}{n-1}s_0^2,
\qquad
\frac1n\sum_i\left(\frac{x_i-\mu}{s_1}\right)^2
=\frac{n-1}{n}.
```

两种约定都可以使用，但必须一致。scikit-learn的StandardScaler使用相当于ddof=0的尺度；它并不保证变换后的数据服从正态分布。[StandardScaler官方文档](https://scikit-learn.org/stable/modules/generated/sklearn.preprocessing.StandardScaler.html)

训练结束后冻结 $\mu,s_0$ 。对验证期、测试期和线上值继续使用这两个参数：

```math
z_{\mathrm{new}}
=\frac{x_{\mathrm{new}}-\mu_{\mathrm{train}}}{s_{\mathrm{train}}}.
```

新数据的均值不必为0，方差不必为1。偏离训练分布可能正是监控系统要识别的变化，不能为让图形“稳定”而随意重新拟合。

若训练值全部相同，尺度为0，应有明确策略。本章将除数设为1，并保留constant标记。训练值于是映射为0；未来出现变化仍能被看见。生产中也可以暂时移除常量特征，但不能静默除以0。

### 21.1.3 缩放怎样改变距离和正则化

对于两个样本 $x,y$ ，标准化后的欧氏距离满足：

```math
\lVert z(x)-z(y)\rVert_2^2
=\sum_{j=1}^p\frac{(x_j-y_j)^2}{s_j^2}.
```

推导：两者都减去相同均值，均值抵消；每一维差值除以尺度，再平方求和。

因此标准化相当于给原始空间的每一维赋权 $1/s_j^2$ 。如果价格水平以千元计、价差以小数计，不缩放就可能让距离几乎只由价格维度决定。K-Means、近邻和使用欧氏距离的异常检测都会受影响。

但标准化不使不同特征独立，也不消除相关性。两列几乎重复的指标，仍可能把同一信息计算两次。

考虑在标准化特征上拟合岭回归：

```math
\min_{a,\beta}
\sum_i\left(y_i-a-\sum_j\beta_jz_{ij}\right)^2
+\lambda\sum_j\beta_j^2.
```

代入 $z_{ij}=(x_{ij}-\mu_j)/s_j$ ，令：

```math
\gamma_j=\frac{\beta_j}{s_j},
\qquad
a'=a-\sum_j\frac{\beta_j\mu_j}{s_j}.
```

预测项变成 $a'+\sum_j\gamma_jx_{ij}$ ，而惩罚项变成：

```math
\lambda\sum_j\beta_j^2
=\lambda\sum_j s_j^2\gamma_j^2.
```

所以“缩放后使用相同惩罚”与“原始单位下对所有系数使用相同惩罚”不是同一个问题。尺度选择实际影响模型偏好。

对理想精确分裂的单变量阈值树，严格单调变换保留排序，通常无需为了量纲而标准化；但直方图分箱、有限精度、正则化实现和非严格单调的截尾仍可能改变结果。

### 21.1.4 最小—最大缩放与向量归一化

**最小—最大缩放（Min–Max Scaling）**把训练范围映射到指定区间。映射到0—1时：

```math
u=\frac{x-x_{\min}}{x_{\max}-x_{\min}}.
```

这里的最小、最大值只能来自训练集。测试值超过训练最大值时，结果可以大于1；这不是计算错误。若业务要求截到0—1，必须另行记录截尾，不能误以为数据天然仍处于训练范围。

**向量归一化（Vector Normalization）**是对一条样本向量进行长度缩放，例如：

```math
\widetilde x=\frac{x}{\lVert x\rVert_2}.
```

这与逐列标准化完全不同。向量归一化保留方向，却丢掉整体幅度。例如收益向量(1,2)与(10,20)归一化后相同。对区分低风险与高风险的市场监控，这种幅度可能十分关键。

零向量没有可除的长度，应保持零并标记，或按任务输出缺失。

### 21.1.5 稳健缩放、分位数与截尾

**稳健缩放（Robust Scaling）**用对极端值较不敏感的统计量作中心和尺度。常见形式：

```math
z_{\mathrm{robust}}
=\frac{x-\mathrm{median}(X_{\mathrm{train}})}
{Q_{0.75}-Q_{0.25}}.
```

分母称为**四分位距（Interquartile Range，IQR）**。它不保证变换后的方差为1；将其称为“稳健标准差”也需要说明校准方式。对于正态分布，IQR约为标准差的1.349倍。

分位数在有限样本中有不同插值定义。本章采用：排序为 $x_{(0)},\ldots,x_{(n-1)}$ ，令：

```math
h=(n-1)q,\quad l=\lfloor h\rfloor,\quad u=\lceil h\rceil,
```

```math
Q_q=x_{(l)}+(h-l)\left(x_{(u)}-x_{(l)}\right).
```

例如[0,10,20,30]的25%分位数为7.5。定义不同可能导致小样本结果不同，不能把这些差异一概归为浮点误差。

IQR可能为0，即使样本并非全常量，例如大量零成交量。本章代码将零尺度设为1，并标记constant；在稳健模式下，该标记精确含义是“所用尺度为零”，不应据此断言所有原始值都相等。[RobustScaler官方文档](https://scikit-learn.org/stable/modules/generated/sklearn.preprocessing.RobustScaler.html)

**截尾或限幅（Clipping）**把超出界限的值限制在边界：

```math
\widetilde z=\min(c,\max(-c,z)).
```

其工程目标可能是防止模型数值被极端输入支配，但它会丢失尾部幅度。例如 $z=-8$ 与 $z=-80$ 都可能变成−4。

因此本章同时保存原值、未截尾的标准化值、截尾值和截尾标记。没有删除真实跳跌，也没有把截尾后的数值冒充原始市场观测。

分位数缩尾（Winsorization）是使用分位数决定边界的相关方法；本章使用预先固定的标准化阈值4，并未估计分位数截尾阈值。

### 21.1.6 对数、幂变换与量纲

非负成交金额通常右偏。可以采用：

```math
y=\log(1+x/c),\qquad x\geq0,\ c>0.
```

$c$ 是具有相同单位的参考尺度，使对数内部无量纲。若金额单位由元改成万元，却不相应调整 $c$ ，变换就变了。

导数为：

```math
\frac{dy}{dx}=\frac{1}{c+x}>0.
```

所以变换保留大小顺序，同时对较大值的局部变化压缩更强。它不能自动把数据变成正态，也不能修复错误金额或未来信息泄漏。

对可正可负的宏观变化，可以定义：

```math
y=\mathrm{sgn}(x)\log(1+|x|/c).
```

这是一种保留符号的教学变换，不等同于所有软件中的Yeo–Johnson变换。

经典Box–Cox变换要求输入正数：

```math
g_\lambda(x)=
\begin{cases}
(x^\lambda-1)/\lambda,&\lambda\neq0,\\[0pt]
\log x,&\lambda=0.
\end{cases}
```

其对数极限来自：

```math
x^\lambda=e^{\lambda\log x}
=1+\lambda\log x+O(\lambda^2).
```

所以 $(x^\lambda-1)/\lambda\to\log x$ 。选择 $\lambda$ 也是拟合行为，必须限制在训练期。FPP3讨论了一个可容纳部分负值的修改版本，不能与这里的经典正值定义混淆。[FPP3第3章](https://otexts.com/fpp3/decomposition.html)

### 21.1.7 固定、滚动与扩展缩放的选择

| 方案 | 参数来源 | 优点 | 主要风险 |
|---|---|---|---|
| 固定训练期 | 一次冻结 | 可比较，容易重现 | 分布漂移时尺度过时 |
| 扩展窗口 | 截至此前的所有历史 | 利用样本多 | 对旧制度依赖较重 |
| 滚动窗口 | 截至此前的最近若干期 | 适应较快 | 参数噪声大，可能消除持续状态 |
| 指数加权 | 旧样本权重逐渐衰减 | 更新成本低 | 半衰期选择影响显著 |

若目的为检测“当前点相对过去是否异常”，应使用包含到 $t-1$ 的位置与尺度：

```math
z_t=\frac{x_t-\mu_{t-1}}{s_{t-1}}.
```

先用 $x_t$ 更新尺度再评分，会让异常点部分进入自己的基准。它不必构成未来泄漏，却改变了检测问题，并可能弱化突变。

批量学习中，交叉验证的每个训练折都要重新拟合缩放器，不能先对全部数据标准化再分折。Pipeline可帮助组织顺序，但不会自动纠正随机切分时间序列等设计错误。[scikit-learn常见陷阱](https://scikit-learn.org/stable/common_pitfalls.html)

## 21.2 动量、趋势、波动、流动性与技术指标

### 21.2.1 收益与动量的逐步推导

设 $P_t\gt 0$ 是可比价格，简单收益为：

```math
r_t=\frac{P_t}{P_{t-1}}-1.
```

因此 $1+r_t=P_t/P_{t-1}$ 。对连续 $k$ 期相乘：

```math
\prod_{j=0}^{k-1}(1+r_{t-j})
=\frac{P_t}{P_{t-1}}\frac{P_{t-1}}{P_{t-2}}
\cdots\frac{P_{t-k+1}}{P_{t-k}}
=\frac{P_t}{P_{t-k}}.
```

**累计动量（Cumulative Momentum）**可定义为：

```math
M_{t,k}=\frac{P_t}{P_{t-k}}-1
=\prod_{j=0}^{k-1}(1+r_{t-j})-1.
```

所以计算5期累计收益需要6个价格，而不是5个价格。

对数收益 $\ell_t=\log(P_t/P_{t-1})$ 可以加总：

```math
\sum_{j=0}^{k-1}\ell_{t-j}
=\log(P_t/P_{t-k}),
\qquad
M_{t,k}=\exp\left(\sum_{j=0}^{k-1}\ell_{t-j}\right)-1.
```

股票需要处理分红、拆股及PIT复权；债券价格收益不等于含票息总回报；商品期货换月可能引入机械跳变；外汇报价方向决定收益符号。本章人工资产没有这些现金流与合约变化，不能直接把示例公式套到未经处理的实盘序列。

动量可以描述近期方向，但一次大涨不等同于牛市。状态还需要波动、流动性、跨资产和宏观证据。

### 21.2.2 简单移动平均与趋势偏离

**简单移动平均（Simple Moving Average，SMA）**：

```math
\mathrm{SMA}_{t,k}
=\frac1k\sum_{j=0}^{k-1}P_{t-j}.
```

前一期窗口减去最旧值、加入最新值，可得递推：

```math
\mathrm{SMA}_{t,k}
=\mathrm{SMA}_{t-1,k}
+\frac{P_t-P_{t-k}}{k}.
```

每次算术更新为常数成本，但仍需保存队列以知道应移除哪个值。存在缺失时，固定长度和有效样本数必须分别处理。

原始价差 $P_t-\mathrm{SMA}_{t,k}$ 有价格单位。跨资产比较更常用相对偏离：

```math
B_{t,k}=\frac{P_t}{\mathrm{SMA}_{t,k}}-1.
```

若全部价格乘以正常数，两者比值不变。这种尺度不变性是可以测试的数学性质。

**居中移动平均（Centered Moving Average）**若同时使用前后时刻，只适合事后平滑；不能把它产生的趋势值当作当时在线特征。

### 21.2.3 指数移动平均、权重与有效样本量

**指数移动平均（Exponential Moving Average，EMA）**规定：

```math
E_0=P_0,\qquad
E_t=(1-\alpha)E_{t-1}+\alpha P_t,
\quad 0<\alpha\leq1.
```

逐步展开：

```math
E_t=(1-\alpha)^tP_0
+\alpha\sum_{j=1}^{t}(1-\alpha)^{t-j}P_j.
```

权重和为：

```math
(1-\alpha)^t
+\alpha\frac{1-(1-\alpha)^t}{1-(1-\alpha)}
=1.
```

这解释了初值的影响：它以 $(1-\alpha)^t$ 衰减，并不是到达某个窗口长度后突然消失。

长期近似权重为 $w_j=\alpha(1-\alpha)^j$ 。若输入独立同分布、方差为 $\sigma^2$ ，则加权平均方差为：

```math
\mathrm{Var}(E)
=\sigma^2\sum_{j=0}^{\infty}w_j^2
=\sigma^2\frac{\alpha^2}{1-(1-\alpha)^2}
=\sigma^2\frac{\alpha}{2-\alpha}.
```

定义具有相同方差的等权平均样本量：

```math
n_{\mathrm{eff}}
=\frac{2-\alpha}{\alpha}.
```

于是常见的 $\alpha=2/(k+1)$ 对应长期权重意义下的 $n_{\mathrm{eff}}=k$ 。这不是有限初始化时的精确样本数，金融序列有自相关时也不能直接用它推断置信区间。

权重半衰期 $h$ 满足：

```math
(1-\alpha)^h=\frac12,
\qquad
h=\frac{\log(1/2)}{\log(1-\alpha)}.
```

上述公式针对 $0\lt \alpha\lt 1$ ； $\alpha=1$ 时只保留当前值。

pandas的ewm默认adjust=True，采用有限权重归一化；adjust=False才对应以上递推。两种方式前期可能不同，缺失值处理也另受ignore_na影响。[pandas ewm文档](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.ewm.html)

本章在缺失价格处重置EMA，下一个有效价格重新初始化。这是显式教学策略，不等同于pandas任一默认缺失配置；实际系统也可保持状态并按真实时间衰减，但必须另定义规则。

### 21.2.4 趋势指标的组合及冗余

**指数平滑异同移动平均（Moving Average Convergence Divergence，MACD）**的一组常见构造为：

```math
D_t=E_t^{(\mathrm{fast})}-E_t^{(\mathrm{slow})},
\qquad
S_t=\mathrm{EMA}(D_t),
\qquad
H_t=D_t-S_t.
```

快均线对新信息反应较快，慢均线保留更长历史；差值表示近期趋势相对较慢趋势的偏离。部分软件把柱状值定义成 $2H_t$ ，因此必须注明具体公式、参数和初始化。

它不是新增了三组独立市场事实，而是对同一价格历史做不同滤波。把多个近似重复的趋势指标全部放进模型，可能加重共线性和多重试验。

跨资产使用时还应考虑用价格归一化该差值，避免黄金价格单位天然压过汇率价格单位。

### 21.2.5 波动率、实现波动与年化

最近 $k$ 个连续简单收益的样本波动率：

```math
\bar r_t=\frac1k\sum_{j=0}^{k-1}r_{t-j},
\qquad
s_t^2=\frac1{k-1}\sum_{j=0}^{k-1}(r_{t-j}-\bar r_t)^2.
```

本章代码用ddof=1，因为这里是在描述局部收益分散程度；这与缩放器使用ddof=0是不同用途。

**实现方差（Realized Variance，RV）**通常由某个较长区间内部的高频收益平方和构造。它与上述去均值样本方差不同：

```math
\sum_{j=1}^{k}r_j^2
=\sum_{j=1}^{k}(r_j-\bar r)^2+k\bar r^2.
```

推导是展开平方，并利用 $\sum_j(r_j-\bar r)=0$ 。不能在接口里把“平方和”“样本标准差”和“年化波动”都命名为vol。

若每年有 $A$ 个同长度收益区间，且收益不相关、单期方差稳定，则：

```math
\mathrm{Var}\left(\sum_{j=1}^{A}r_j\right)=A\sigma^2,
\qquad
\sigma_{\mathrm{annual}}=\sqrt A\,\sigma.
```

有自相关时还要增加交叉协方差项。分钟行情的每年区间数还依赖交易日历，不能机械乘 $\sqrt{252}$ 。本章实验步长是人工等间距，因此不年化。

### 21.2.6 RSI与真实波幅：定义不等于交易结论

**相对强弱指数（Relative Strength Index，RSI）**比较同一资产历史上涨与下跌幅度，并不是直接比较两项资产。

令价格变化 $\Delta P_t=P_t-P_{t-1}$ ，分解：

```math
U_t=\max(\Delta P_t,0),\qquad
D_t=\max(-\Delta P_t,0).
```

对上涨和下跌幅度分别平滑为 $G_t,L_t$ 。Wilder型平滑在用首 $k$ 个变化的均值初始化之后，采用：

```math
G_t=\frac{(k-1)G_{t-1}+U_t}{k},
\qquad
L_t=\frac{(k-1)L_{t-1}+D_t}{k}.
```

当 $L_t\gt 0$ 时：

```math
\mathrm{RSI}_t
=100-\frac{100}{1+G_t/L_t}
=\frac{100G_t}{G_t+L_t}.
```

第二个形式来自通分，更便于讨论边界：

- 仅上涨、没有下跌：100。
- 仅下跌、没有上涨：0。
- 涨跌幅度全为0：分母为0；本章习题选择50并附带“平坦”标记。

最后一种取值是约定，不是由原始分式推出的唯一答案。Fidelity的官方指标说明列出了RSI基本计算式；平台之间还应核对平滑及初始化。[RSI指标说明](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/RSI)

**真实波幅（True Range，TR）**的一般定义为：

```math
\mathrm{TR}_t
=\max\left(H_t-L_t,\ |H_t-C_{t-1}|,\ |L_t-C_{t-1}|\right).
```

这里 $H,L,C$ 分别是最高、最低、收盘价。第二、三项纳入了相对前收盘的跳空。对TR平滑得到**平均真实波幅（Average True Range，ATR）**；它有价格单位，不是收益率标准差。若要无量纲，可另报告ATR/价格。

本章主程序没有OHLC数据，因此不伪造ATR。RSI“高位”或MACD某种交叉也不自动证明未来会反转；这些只是待检验的描述变量。

### 21.2.7 流动性特征与单位陷阱

**报价相对价差（Relative Quoted Spread）**：

```math
m_t=\frac{a_t+b_t}{2},
\qquad
q_t=\frac{a_t-b_t}{m_t},
\qquad
q_t^{(\mathrm{bp})}=10^4q_t.
```

其中 $a_t,b_t$ 是卖价、买价；1基点等于0.0001。价差宽通常意味着较高的即时往返交易成本，但不包含全部深度、冲击或延迟成本。

**Amihud非流动性代理量**使用绝对收益与成交金额之比的时间平均：

```math
I_{t,k}=\frac1k\sum_{j=0}^{k-1}
\frac{|r_{t-j}|}{V_{t-j}^{(\mathrm{money})}}.
```

原论文使用股票日收益与美元成交金额，本章将相同代数形式用于人工区间，并称为impact5代理，不能把它当作已估计出的因果价格冲击系数。[Amihud（2002）论文](https://www.cis.upenn.edu/~mkearns/finread/amihud.pdf)

分母必须是金额，不是随意把股数、手数、债券张数和外汇报价次数放在一起。跨币种比较要采用当时可用汇率转换，期货需处理合约乘数，场外外汇未必存在全市场成交总额。

当成交金额为0，比值没有定义。不能填0，否则把“不可测或极少交易”解释成“非常有流动性”。本章保留该特征为空，其他仍可计算的特征不一并删除。

## 21.3 宏观惊喜、滞后因子与在线离线一致性

### 21.3.1 宏观水平、变化与增长不是同一种特征

对正值水平序列 $X_t$ ，环比与同比可以定义为：

```math
g_t^{(1)}=\frac{X_t}{X_{t-1}}-1,
\qquad
g_t^{(12)}=\frac{X_t}{X_{t-12}}-1.
```

它们分别比较上一期和去年同期，适用于月度示例。必须核对是否季调、是否名义值、是否同基期、分子分母是否属于一致知识截面。

若输入本来就是“CPI同比为2.3%”，再对2.3计算同比，并不会得到通常意义的物价通胀率。2.3%到2.7%的直接差为0.4个百分点，不是“上涨0.4%”。

季度增速若按复利换算成年率：

```math
g_{\mathrm{ann}}=(1+g_{\mathrm{quarter}})^4-1.
```

这是“同样季度增长重复四次”的换算，不是预测未来四季必然如此。ALFRED帮助列出了增长变换公式，可用于核对接口口径。[ALFRED帮助](https://alfred.stlouisfed.org/help)

“宏观因子”在本章泛指具有宏观含义的输入变量；它不一定是资产定价中的可交易风险因子，也不一定是因子分析估计的潜变量。

### 21.3.2 宏观惊喜的构造与时点

**宏观惊喜或意外（Macroeconomic Surprise）**衡量首次公布值与公布前预期的差异。

设事件 $j$ 的首次值为 $A_j^{(1)}$ ，公布前冻结的预期为 $C_j^-$ ：

```math
u_j=A_j^{(1)}-C_j^-.
```

若同类历史惊喜的训练期尺度为 $s_{u,\mathrm{train}}\gt 0$ ，可定义：

```math
S_j=\frac{u_j}{s_{u,\mathrm{train}}}.
```

这里采用不减均值的事件研究式标准化，保留“符合共识时为0”的含义。若改成 $(u_j-\bar u)/s_u$ ，衡量的是相对历史预测偏差均值的偏离，应另起名称。

不同机构的预期样本、调查截止和中位数/均值口径都会改变共识。不能在发布后再下载一份已更新的预测表，就认定那是发布前共识。

Andersen等人的宏观公告研究把实际公布与预期的差异用于解释汇率价格发现；本章只借鉴“区分实现值和事前预期”的研究设计，不移用论文系数或声称复现其经验结果。[原论文与书目信息](https://pubs.aeaweb.org/doi/10.1257/000282803321455151)

修订量另定义为：

```math
d_j^{(v)}=A_j^{(v)}-A_j^{(1)}.
```

首次2.3%、事前共识2.1%、后来修订2.7%，则首次惊喜0.2个百分点、修订0.4个百分点。不能把后来2.7减去原共识得到0.6，并把这个值回填成最初公告惊喜。

### 21.3.3 低频信息进入高频面板

一条月度宏观数据可以在发布后保持为当前已知水平，但复制到一万条行情记录并不产生一万个独立宏观观测。

建议同时保留：

- 当前水平、统计期及版本；
- 首次惊喜与首次可用时间；
- 最新修订及修订可用时间；
- 距发布或可用时刻的年龄；
- 当前是否新事件、是否缺失、是否撤回。

若希望描述某次事件随时间衰减的影响，可作教学假设：

```math
F(t)=u_j\,2^{-(t-a_j)/h},
\qquad t\geq a_j,\ h>0.
```

其中 $a_j$ 是事件对系统可用的时刻， $h$ 是半衰期。因为 $2^{-h/h}=1/2$ ，经过一个半衰期幅度减半。

它只是一种特征设计，不证明金融市场冲击真实按指数衰减。 $h$ 的选择应在训练、验证阶段完成。实验取10个人工步长；既不是10分钟，也不是10个交易日。

对多事件累积可以对所有已可用事件求和，但这与“只表示最新统计期惊喜”是不同特征。本章代码只保留最新统计期，新的统计期发布时切换，不把多个事件叠加。

### 21.3.4 滞后与可用性不能相互替代

业务滞后一个月，是取上一统计期；系统延迟一天，是信息晚一天才能使用。这两个操作不能混为一谈。

对数据行机械shift(1)，只把它移到前一行。如果原表按天、按事件或有缺失，前一行不一定是前一个月，更不一定恰好满足发布可用性。

正确顺序是：

1. 按第20章规则取得截至决策时刻可见的版本。
2. 明确选择哪个统计期或哪个事件。
3. 计算业务滞后、变化或惊喜。
4. 记录该次结果依赖的全部版本与就绪时间。

跨资产解释也应具体：增长意外可能影响股票现金流预期，通胀意外可能改变名义利率与债券估值，商品和汇率反应还受供需、政策及计价方向影响。不能只凭“惊喜为正”就把所有资产统一标为利好。

### 21.3.5 在线离线一致性究竟比较什么

**在线离线偏差（Training–Serving Skew）**指训练或离线研究中的特征构造与线上服务中的构造不同。

应逐项核对：输入版本、时间边界、窗口长度、缺失策略、EMA初值、ddof、缩放器、金额单位和浮点类型。

离线程序若对每个历史点重新取全段数据计算，线上程序若逐条更新状态，两者在相同输入和契约下应相等或在规定浮点容差内一致。

测试不能只让两边调用同一个函数，否则同一个错误会同时出现。对EMA，本章测试用展开后的加权和作为独立参考；对动量，用逐期复利乘积核对端点比值。

此外，五期窗口的输入列表不能代表EMA全部血缘：EMA仍依赖连续段更早的价格。实验保存ema_start_id，结合完整有序原始输入可重建该连续段。

## 21.4 完整实验：可审计的四资产特征流水线

### 21.4.1 实验契约与运行方法

生成4项人工资产各96个等间距价格区间，共384行。随机种子20261108。人工异常为：

- EQ_DEMO第55期价格缺失；记录保留。
- FX_DEMO第60期成交金额为0。
- EQ_DEMO第72期简单收益固定为−8%；真实保留。
- 9月宏观首次值2.3%、事前共识2.1%，后来修订2.7%。
- 一个发布后才可用的“共识”故意放入输入，用于验证排除。
- 10月首次值2.4%、事前共识2.5%。

区间编号为t，数据在t+1时可用；特征处理耗时假定为0。训练数据ready不晚于40，缩放器在41就绪，从t=40开始输出标准化特征。不是秒级真实日志，也没有真实交易日历。

每个资产的6个特征为ret1、mom5、vol5、ema_gap、spread_bps、impact5。为让缩放比较使用同一批训练样本，拟合时只使用6个特征同时非空的行；每资产35行。线上则逐特征保留缺失，不整行删除。

该完整案例没有训练市场状态分类器；训练阶段仅拟合数值变换，避免把特征实验误写成状态识别准确率实验。

仅用现有Anaconda Python3.13.5标准库：

```powershell
& 'D:\Anaconda\python.exe' -X utf8 教材/code/ch21/features_lab.py
& 'D:\Anaconda\python.exe' -X utf8 -m unittest discover -s 教材/code/ch21 -v
```

程序保存原始输入、全部未缩放特征、两种缩放器、线上输出、宏观输入及快照到results.json，并在manifest.json保存环境、程序哈希和结果哈希。

[主程序](./code/ch21/features_lab.py)与[14项测试](./code/ch21/test_features_lab.py)如下配套。金额统一为人工共同货币；没有实际汇率转换或合约乘数接入。

### 21.4.2 完整主程序

```python
"""Causal feature lab: synthetic equal-step bars, standard library only."""
from collections import deque
from datetime import datetime, timezone
from pathlib import Path
from statistics import fmean, median, pstdev, stdev
import hashlib
import json
import math
import platform
import random

ASSETS = ("EQ_DEMO", "BOND_DEMO", "GOLD_DEMO", "FX_DEMO")
NAMES = ("ret1", "mom5", "vol5", "ema_gap", "spread_bps", "impact5")
WINDOW, ALPHA, TRAIN_END, MODEL_READY = 5, 0.3, 40, 41


def valid_price(x):
    return x is not None and math.isfinite(x) and x > 0


class Engine:
    def __init__(self):
        self.last = -1
        self.rows = deque(maxlen=WINDOW + 1)
        self.ema = None
        self.ema_start = None

    def step(self, b):
        if b["t"] != self.last + 1 or b["ready"] != b["t"] + 1:
            raise ValueError("expected consecutive finalized synthetic bars")
        p = b["price"]
        if p is not None and not valid_price(p):
            raise ValueError("invalid price; upstream quarantine required")
        if not math.isfinite(b["notional"]) or b["notional"] < 0:
            raise ValueError("invalid notional")
        if p is not None and not (math.isfinite(b["bid"]) and math.isfinite(b["ask"])
                                  and 0 < b["bid"] <= b["ask"]):
            raise ValueError("invalid quote")
        self.last = b["t"]
        self.rows.append(dict(b))
        if p is None:
            self.ema_start = None
        elif self.ema is None:
            self.ema_start = b["id"]
        self.ema = (None if p is None else p if self.ema is None
                    else (1 - ALPHA) * self.ema + ALPHA * p)
        rows = list(self.rows)
        x = dict.fromkeys(NAMES)
        if p is not None:
            mid = (b["bid"] + b["ask"]) / 2
            x["spread_bps"] = 10000 * (b["ask"] - b["bid"]) / mid
            x["ema_gap"] = p / self.ema - 1
        if len(rows) >= 2 and all(valid_price(r["price"]) for r in rows[-2:]):
            x["ret1"] = rows[-1]["price"] / rows[-2]["price"] - 1
        if len(rows) == WINDOW + 1 and all(valid_price(r["price"]) for r in rows):
            returns = [rows[i]["price"] / rows[i-1]["price"] - 1
                       for i in range(1, len(rows))]
            x["mom5"] = rows[-1]["price"] / rows[0]["price"] - 1
            x["vol5"] = stdev(returns)
            notionals = [r["notional"] for r in rows[1:]]
            if all(v > 0 for v in notionals):
                x["impact5"] = fmean(abs(r) / v for r, v in zip(returns, notionals))
        return {"asset": b["asset"], "t": b["t"], "ready": b["ready"],
                "x": x, "window_ids": [r["id"] for r in rows],
                "ema_start_id": self.ema_start}


def panel(bars):
    engines = {a: Engine() for a in ASSETS}
    return [engines[b["asset"]].step(b) for b in bars]


def quantile(values, q):
    s = sorted(values)
    h = (len(s) - 1) * q
    lo, hi = math.floor(h), math.ceil(h)
    return s[lo] + (h - lo) * (s[hi] - s[lo])


def fit(rows, kind="standard"):
    if kind not in ("standard", "robust"):
        raise ValueError("unknown scaler")
    if any(r["ready"] > TRAIN_END for r in rows):
        raise ValueError("future row in training")
    if not rows:
        raise ValueError("empty training")
    params = {}
    for a in ASSETS:
        usable = [r for r in rows if r["asset"] == a
                  and all(r["x"][k] is not None for k in NAMES)]
        if len(usable) < 2:
            raise ValueError("insufficient complete training rows")
        params[a] = {}
        for k in NAMES:
            values = [r["x"][k] for r in usable]
            center = fmean(values) if kind == "standard" else median(values)
            scale = (pstdev(values) if kind == "standard"
                     else quantile(values, 0.75) - quantile(values, 0.25))
            params[a][k] = {"center": center, "scale": scale or 1.0,
                           "constant": scale == 0, "n": len(values)}
    return {"kind": kind, "ready": MODEL_READY, "train_end": TRAIN_END,
            "params": params}


def transform(row, scaler):
    if row["ready"] < scaler["ready"]:
        raise ValueError("scaler not ready for this historical decision")
    z, clipped, flags = {}, {}, {}
    for k, value in row["x"].items():
        p = scaler["params"][row["asset"]][k]
        z[k] = None if value is None else (value - p["center"]) / p["scale"]
        clipped[k] = None if z[k] is None else max(-4.0, min(4.0, z[k]))
        flags[k] = z[k] is not None and abs(z[k]) > 4
    return {**row, "z": z, "clipped_z": clipped, "clipped": flags,
            "scaler_kind": scaler["kind"]}


def macro_inputs():
    releases = [
        {"id": "sep-v1", "period": "2026-09", "rev": 1,
         "pub": 45, "ready": 46, "value": 2.3},
        {"id": "sep-v2", "period": "2026-09", "rev": 2,
         "pub": 65, "ready": 66, "value": 2.7},
        {"id": "oct-v1", "period": "2026-10", "rev": 1,
         "pub": 80, "ready": 81, "value": 2.4},
    ]
    forecasts = [
        {"id": "sep-pre", "period": "2026-09", "ready": 44, "value": 2.1},
        {"id": "sep-late", "period": "2026-09", "ready": 46, "value": 2.25},
        {"id": "oct-pre", "period": "2026-10", "ready": 79, "value": 2.5},
    ]
    return releases, forecasts


def macro_at(cut, releases, forecasts):
    visible = [r for r in releases if r["ready"] <= cut]
    if not visible:
        return None
    period = max(r["period"] for r in visible)
    current = max((r for r in visible if r["period"] == period),
                  key=lambda r: r["rev"])
    first = next((r for r in visible if r["period"] == period and r["rev"] == 1),
                 None)
    pre = ([] if first is None else
           [f for f in forecasts if f["period"] == period
            and f["ready"] < first["pub"]])
    forecast = max(pre, key=lambda f: f["ready"]) if pre else None
    surprise = None if forecast is None else first["value"] - forecast["value"]
    age = None if first is None else cut - first["ready"]
    return {"period": period, "level": current["value"], "id": current["id"],
            "first_id": None if first is None else first["id"],
            "forecast_id": None if forecast is None else forecast["id"],
            "surprise_pp": surprise,
            "revision_pp": None if first is None else current["value"] - first["value"],
            "first_age": age,
            "decayed_surprise": None if surprise is None else surprise * 2 ** (-age / 10)}


def samples(n=96):
    rng = random.Random(20261108)
    prices = dict(zip(ASSETS, (100.0, 99.0, 2000.0, 7.0)))
    bars = []
    for t in range(n):
        for j, a in enumerate(ASSETS):
            r = 0.0003 * (j + 1) + rng.gauss(0, 0.001 * (j + 1))
            if a == "EQ_DEMO" and t == 72:
                r = -0.08
            prices[a] *= 1 + r
            p = None if a == "EQ_DEMO" and t == 55 else prices[a]
            spread = 2 + j + (t % 5) * 0.2
            bars.append({
                "id": f"{a}-{t}", "asset": a, "t": t, "ready": t + 1, "price": p,
                "bid": None if p is None else p * (1 - spread / 20000),
                "ask": None if p is None else p * (1 + spread / 20000),
                "notional": 0.0 if a == "FX_DEMO" and t == 60
                            else 1e6 * (j + 1) * (1 + (t % 7) / 10)
            })
    return bars


def run():
    bars = samples()
    raw = panel(bars)
    training = [r for r in raw if r["ready"] <= TRAIN_END]
    standard, robust = fit(training), fit(training, "robust")
    online = [transform(r, standard) for r in raw if r["ready"] >= MODEL_READY]
    releases, forecasts = macro_inputs()
    return {
        "data_kind": "SYNTHETIC", "seed": 20261108,
        "clock": "equal steps; bar t available at t+1; zero feature latency",
        "contract": {"window": WINDOW, "alpha": ALPHA, "ddof_vol": 1,
                     "ddof_scaler": 0, "clip": 4, "ema_gap_policy": "reset",
                     "notional_unit": "common synthetic currency"},
        "bars": bars, "raw_features": raw,
        "scalers": {"standard": standard, "robust": robust},
        "online": online, "macro_inputs": [releases, forecasts],
        "macro": {str(t): macro_at(t, releases, forecasts)
                  for t in (45, 46, 56, 66, 81)}
    }


def main():
    result = run()
    stamp = datetime.now(timezone.utc).strftime("%Y%m%dT%H%M%S_%fZ")
    out = Path(__file__).parent / "runs" / ("run_" + stamp)
    out.mkdir(parents=True)
    p = out / "results.json"
    p.write_text(json.dumps(result, indent=2, ensure_ascii=False, allow_nan=False),
                 encoding="utf-8")
    manifest = {
        "python": platform.python_version(),
        "program_sha256": hashlib.sha256(Path(__file__).read_bytes()).hexdigest(),
        "results_sha256": hashlib.sha256(p.read_bytes()).hexdigest(),
        "bars": len(result["bars"]), "online_rows": len(result["online"]),
        "clipped_rows": sum(any(r["clipped"].values()) for r in result["online"])
    }
    (out / "manifest.json").write_text(json.dumps(manifest, indent=2), encoding="utf-8")
    print(json.dumps({"run_dir": str(out), **manifest}, ensure_ascii=False))


if __name__ == "__main__":
    main()
```

### 21.4.3 代码机制与实际结果

Engine为每项资产维护独立队列与EMA。窗口最多保存6个价格；只有连续6个有效价格才产生5期动量、波动及金额冲击代理。成交金额不合格只使impact5为空，不会把其他可计算值一并删除。

价格缺失后，55和56期都没有有效单期收益；5期动量与波动在55—60期为空，61期恢复。56期EMA重新初始化，因此相对偏离为0，但它表示新连续段的起点，不代表市场突然回归长期均衡。

fit只接受ready不晚于40的训练行；如果误传入全表，直接报错。transform拒绝把41才就绪的缩放器用于更早历史决策。固定阈值4只作用于另存的clipped_z。

实际运行得到384行原始特征、224行线上特征，其中15行至少有一个标准化特征被限幅。这个计数是人工实验结果，不是误报率。

### 21.4.4 验证与工程边界

14项测试覆盖：独立批量参考、预热、缺失断点、零金额、训练标准化恒等式、常量和分位数、未来训练拒绝、未来扰动、前缀重放、限幅留证、顺序与坏价格、价格单位缩放不变性、宏观共识时点与修订、宏观前缀及缺失预期。

所谓价格尺度不变性，是把价格及买卖报价同时乘100而不改变成交金额的计价口径；若连金额货币单位也改变，impact5会按单位改变，不能要求仍然不变。

本例的有序输入来自第17—20章之后的标准化边界。它拒绝跳号和乱序，不负责水位线、重复投递、迟到价格修订或宏观撤回。遇到这些情况应先交给上游版本与对齐模块。

算法成本：每条记录重新扫描固定窗口，成本为 $O(k)$ ，每资产状态为 $O(k)$ ；EMA更新为常数成本。若改用窗口和与平方和，可降低算术成本，但大数相减会引起精度损失，应结合稳定方差算法、周期重算与独立校验。

本例为审计保留全部输出，因此总体保存空间随样本数增长。完整批量参考测试的EMA展开也较慢，它用于核对正确性，不是生产吞吐实现。

生产系统还应补充：数值溢出检测、特征Schema与单位版本、独立质量状态、不可变缩放器标识、模型依赖就绪门控、状态持久化与故障重放。当前字典与批量JSON文件不等同于持久特征服务。

## 本章总结

数值变换会改变距离、正则化与异常幅度，必须像模型一样限制拟合时点并保存版本。标准化不保证正态，也不消除相关性；稳健缩放和截尾具有不同目标。

技术指标是对同一历史信息的滤波和统计摘要。窗口、初始化、缺失、年化与单位决定其真实含义。公式相似不意味着两个软件默认实现相同。

宏观水平、增长、首次惊喜和修订必须分开，预期数据也受PIT约束。在线离线一致性需要独立参考计算及完整输入血缘。

## 详细参考答案

### 题1

均值为2，离差为−1、0、1，所以：

```math
s_0^2=\frac{1+0+1}{3}=\frac23,
\qquad
z_{\mathrm{test}}=\frac{5-2}{\sqrt{2/3}}\approx3.674235.
```

若错误加入测试值，均值变为2.75，平方离差和为：

```math
(-1.75)^2+(-0.75)^2+0.25^2+2.25^2=8.75.
```

尺度为 $\sqrt{8.75/4}=\sqrt{2.1875}$ ，对应测试z约1.521278。测试点改变了自己的中心与尺度，原本显著偏离训练分布的值看起来更普通。这就是缩放参数泄漏的直接例子。

### 题2

```math
d_{\mathrm{scaled}}^2
=(10/100)^2+(0.01/0.01)^2
=0.01+1=1.01.
```

原始距离平方为100.0001，几乎完全由第一维决定；标准化后第二维是一整个训练尺度，反而贡献更大。哪一种距离合适由任务决定，但不能让单位选择偶然决定权重。

### 题3

中位数15；25%分位数7.5，75%分位数22.5，因此IQR=15：

```math
z_{\mathrm{robust}}(40)=\frac{40-15}{15}=\frac53.
```

IQR为0时可采用备用尺度、保留原值或暂不使用该特征。本章采用除数1和零尺度标记，但稳健模式的标记不能解释成所有观测完全相同。还应记录非零频率，避免稀疏事件被误删。

### 题4

```math
(1.10)(0.90)(1.05)-1
=1.0395-1
=3.95\%.
```

直接相加是5%，忽略了复利交叉项。

### 题5

```math
E_0=100,\qquad
E_1=0.5(100)+0.5(102)=101,
```

```math
E_2=0.5(101)+0.5(101)=101.
```

展开为：

```math
E_2=0.25P_0+0.25P_1+0.5P_2.
```

长期有效样本量：

```math
n_{\mathrm{eff}}=(2-0.5)/0.5=3.
```

半衰期为1个步长。有限时刻的权重平方和为0.375，对应有效样本量约2.6667；这也说明长期公式不是启动期的精确值。

### 题6

均值0，平方和为0.0002，样本方差为0.0002/2=0.0001，样本标准差为0.01，即1%。

平方和的平方根为 $\sqrt{0.0002}\approx0.0141421$ ，即1.41421%。**二者在本例并不相等**；题干“恰好相等”是需要识别的错误前提。

一般关系是平方和等于去均值平方和加上样本数乘均值平方；即使均值为0，样本标准差仍有分母 $k-1$ 。不能把平方和的平方根直接叫作单期样本标准差。

### 题7

中间价100，价差0.2：

```math
q^{(\mathrm{bp})}
=10^4\frac{0.2}{100}
=20.
```

两期比值分别为：

```math
0.01/10^6=10^{-8},
\qquad
0.02/(2\times10^6)=10^{-8}.
```

平均仍为 $10^{-8}$ ，单位是“每元”。若金额数字改用万元，两个分母变为100、200，代理量变为 $10^{-4}$ ，单位是“每万元”。数值放大一万倍，经济信息没有变化，单位标签必须随之改变。

### 题8

首次惊喜0.2个百分点，标准化为：

修订为0.4个百分点。用(2.7−2.1)/0.1得到6，混合了首次意外与后续修订，而且使用了首次公告时尚不可得的信息。

### 题10

以下程序仅接受无缺失的正价格，返回最后一个RSI及平坦标记。第一个RSI用首k个变化的均值初始化，之后逐条执行Wilder递推。

```python
import math

def last_rsi(prices, k=14):
    if type(k) is not int or k < 1 or len(prices) < k + 1:
        raise ValueError("need positive k and at least k+1 prices")
    if any(not math.isfinite(p) or p <= 0 for p in prices):
        raise ValueError("need finite positive prices without gaps")
    changes = [b - a for a, b in zip(prices, prices[1:])]
    gain = sum(max(d, 0) for d in changes[:k]) / k
    loss = sum(max(-d, 0) for d in changes[:k]) / k
    for d in changes[k:]:
        gain = ((k - 1) * gain + max(d, 0)) / k
        loss = ((k - 1) * loss + max(-d, 0)) / k
    flat = gain + loss == 0
    return (50.0 if flat else 100 * gain / (gain + loss)), flat

assert last_rsi([1, 2, 3, 4], 2) == (100.0, False)
assert last_rsi([4, 3, 2, 1], 2) == (0.0, False)
assert last_rsi([2, 2, 2, 2], 2) == (50.0, True)
print("RSI boundary assertions passed")
```

平坦时50只是本实现约定。接入缺失价格时应先设计重新预热或断点策略，不能直接删除缺失行再把两边价格当成相邻交易期。
